面向对象编程（OOP）使用对象和类来组织程序。下面是一个类的例子：

class Car:
    max_tires = 4

    def __init__(self, color):
        self.tires = Car.max_tires
        self.color = color

    def drive(self):
        if self.tires < Car.max_tires:
            return self.color + ' car cannot drive!'
        return self.color + ' car goes vroom!'

    def pop_tire(self):
        if self.tires > 0:
            self.tires -= 1

类（Class）：对象的类型。Car 类（如上所示）描述了所有 Car 对象的特征。

对象（Object）：类的一个实例。在 Python 中，通过调用类来创建新对象。

>>> ferrari = Car('red')

这里，ferrari 是一个绑定到 Car 对象的名字。

类属性：属于类的变量，通过点号访问。Car 类有一个 max_tires 属性。

>>> Car.max_tires
4

实例属性：属于某个具体对象的变量。每个 Car 对象都有一个 tires 属性和一个 color 属性。与类属性一样，实例属性也通过点号访问。

>>> ferrari.color
'red'
>>> ferrari.tires
4
>>> ferrari.color = 'green'
>>> ferrari.color
'green'

方法：属于对象的函数，通过点号调用。按照约定，方法的第一个参数是 self。

当调用对象的某个方法时，该对象会被隐式地作为 self 的参数传入。例如，ferrari 对象的 drive 方法是用空括号调用的，因为 self 被隐式地绑定到 ferrari 对象。

>>> ferrari = Car('red')
>>> ferrari.drive()
'red car goes vroom!'

我们也可以调用最初的 Car.drive 函数。这个原始函数不属于任何特定的 Car 对象，所以我们必须显式地为 self 传入参数。

>>> ferrari = Car('red')
>>> Car.drive(ferrari)
'red car goes vroom!'

__init__：一种特殊函数，在创建类的新实例时会自动调用。

注意 drive 方法接收 self 作为参数，但看起来我们并没有传入它！这是因为点号表示法隐式地帮我们把 ferrari 作为 self 传了进去。所以在这个例子里，self 绑定到全局帧中名为 ferrari 的那个对象。

求值表达式 Car('red') 时，Python 会创建一个新的 Car 对象。然后，Python 调用 Car 类的 __init__ 函数，把 self 绑定到新对象，把 color 绑定到 'red'。


树

回顾一下树这种抽象数据类型：一棵树被定义为有一个标签和若干分支。之前我们用 Python 列表实现了树的抽象。现在我们看看另一种用对象实现的方式：

class Tree:
    def __init__(self, label, branches=[]):
        for b in branches:
            assert isinstance(b, Tree)
        self.label = label
        self.branches = branches

    def is_leaf(self):
        return not self.branches

使用这种实现，我们可以通过属性赋值来修改树，而之前用列表的实现做不到这一点。这也是我们有时把这些对象称为「可变树」的原因。

>>> t = Tree(3, [Tree(4), Tree(5)])
>>> t.label = 5
>>> t.label
5

为了避免为相似的类重复定义属性和方法，我们可以写一个基类，让更专门的类继承它。例如，我们可以写一个叫做 Pet 的类，并把 Dog 定义为 Pet 的子类：

class Pet:
    def __init__(self, name, owner):
        self.is_alive = True    # It's alive!!!
        self.name = name
        self.owner = owner
    def eat(self, thing):
        print(self.name + " ate a " + str(thing) + "!")
    def talk(self):
        print(self.name)

class Dog(Pet):
    def talk(self):
        super().talk()
        print('This Dog says woof!')

继承表示两个或多个类之间的层次关系，其中一个类是另一个类更具体的版本：狗是一种宠物。（在面向对象语言中，我们用「is a」来描述这类关系，而不是指 Python 的 is 运算符。）

由于 Dog 继承自 Pet，Dog 类也会继承 Pet 类的方法，因此我们不必重新定义 __init__ 或 eat。但我们希望每只 Dog 都用 Dog 特有的方式说话，所以可以重写 talk 方法。

我们可以用 super() 来表示 self 的超类，并像超类的实例一样访问任何超类方法。例如，Dog 类中的 super().talk() 会调用 Pet 类中的 talk 方法，但传入的 self 是 Dog 实例。
