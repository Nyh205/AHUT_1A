Q2：冰雹数列

道格拉斯·霍夫施塔特获得普利策奖的著作《哥德尔、艾舍尔、巴赫》提出了下面这个数学谜题。

  1. 选一个正整数 n 作为起点。
  2. 如果 n 是偶数，就把它除以 2。
  3. 如果 n 是奇数，就把它乘以 3 再加 1。
  4. 重复这个过程，直到 n 等于 1。

数字 n 会上下起伏，但最终都会停在 1（至少对所有试过的数都是这样——没有人证明过这个序列一定会终止）。类似地，冰雹在大气中上下翻滚，最终落到地面。

accumulate 有以下参数：

  • fuse：一个双参数函数，规定当前项如何与之前累加的结果融合
  • start：开始累加时的值
  • n：一个非负整数，表示要融合的项数
  • term：一个单参数函数；term(i) 是序列的第 i 项

实现 accumulate，它用 fuse 函数把由 term 定义的序列的前 n 项与 start 值融合起来。

例如，accumulate(add, 11, 3, square) 的结果是

add(11,  add(square(1), add(square(2),  square(3)))) =
    11 +     square(1) +    square(2) + square(3)    =
    11 +     1         +    4         + 9            = 25

假设 fuse 满足交换律 fuse(a, b) == fuse(b, a) 和结合律 fuse(fuse(a, b), c) == fuse(a, fuse(b, c))。
