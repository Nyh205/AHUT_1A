可变的树

Tree 实例有两个实例属性：

  • label 是存储在树根处的值。
  • branches 是一个由 Tree 实例组成的列表，保存了树中其余部分的标签。

Tree 类（省略了 __repr__ 和 __str__ 方法）的定义如下：

class Tree:
    """A tree has a label and a list of branches.

    >>> t = Tree(3, [Tree(2, [Tree(5)]), Tree(4)])
    >>> t.label
    3
    >>> t.branches[0].label
    2
    >>> t.branches[1].is_leaf()
    True
    """
    def __init__(self, label, branches=[]):
        self.label = label
        for branch in branches:
            assert isinstance(branch, Tree)
        self.branches = list(branches)

    def is_leaf(self):
        return not self.branches

要用标签 x（任意值）和分支列表 bs（由 Tree 实例组成的列表）构造一个 Tree 实例并把它命名为 t，可以写 t = Tree(x, bs)。

对于树 t：

  • 它的根标签可以是任意值，t.label 求值的结果就是它。
  • 它的分支总是 Tree 实例，t.branches 求值的结果是它的分支列表。
  • 如果 t.branches 为空，t.is_leaf() 返回 True，否则返回 False。
  • 要构造一个标签为 x 的叶子，写 Tree(x)。

显示一棵树 t：

  • repr(t) 返回一个 Python 表达式，对它求值会得到一棵等价的树。
  • str(t) 为每个标签输出一行，其缩进比它的父节点多一级，子节点显示在父节点下方。
>>> t = Tree(3, [Tree(1, [Tree(4), Tree(1)]), Tree(5, [Tree(9)])])

>>> t         # displays the contents of repr(t)
Tree(3, [Tree(1, [Tree(4), Tree(1)]), Tree(5, [Tree(9)])])

>>> print(t)  # displays the contents of str(t)
3
  1
    4
    1
  5
    9

修改（也就是 mutate）一棵树 t：

  • t.label = y 把 t 的根标签改为 y（任意值）。
  • t.branches = ns 把 t 的分支改为 ns（由 Tree 实例组成的列表）。
  • 修改 t.branches 会改变 t。例如，t.branches.append(Tree(y)) 会把一个标签为 y 的叶子添加为最右边的分支。
  • 修改 t 中任意一个分支都会改变 t。例如，t.branches[0].label = y 会把最左边分支的根标签改为 y。
>>> t.label = 3.0
>>> t.branches[1].label = 5.0
>>> t.branches.append(Tree(2, [Tree(6)]))
>>> print(t)
3.0
  1
    4
    1
  5.0
    9
  2
    6

下面总结了以函数式抽象实现的树数据抽象与以类实现的树数据抽象之间的区别：

- 树的构造函数与选择函数 Tree 类
构造树 给定一个标签和一个分支列表来构造一棵树时，我们调用 tree(label, branches) 给定一个标签和一个分支列表来构造一个树对象时，我们调用 Tree(label, branches)（它会调用 Tree.__init__ 方法）。
根标签与分支 要获取树 t 的标签或分支，我们分别调用 label(t) 或 branches(t) 要获取树 t 的标签或分支，我们分别访问实例属性 t.label 或 t.branches。
可变性 函数式的树数据抽象是不可变的（在遵守其抽象屏障的前提下），因为我们无法给调用表达式赋值 Tree 实例的 label 和 branches 属性可以被重新赋值，从而修改这棵树。
判断树是否为叶子 要判断树 t 是否为叶子，我们调用函数 is_leaf(t) 要判断树 t 是否为叶子，我们调用方法 t.is_leaf()。这个方法只能在 Tree 对象上调用。

使用 Tree 类

第 2 题：最宽的一层

写一个函数，接收一个 Tree 对象，返回元素个数最多的那一层的所有元素。如果两层的元素个数相同，则选择较浅的那一层。

在这个问题中，你可能会发现使用 sum 的第二个可选参数很有帮助，它提供一个起始值。被求和序列中的所有项都会拼接到这个起始值上。默认情况下，start 为 0，这让你能对一串数字求和。我们给出一个以列表为起始值的 sum 示例，它可以把列表中的项拼接起来。

你的答案
参考答案 
def widest_level(t):
    """
    >>> sum([[1], [2]], [])
    [1, 2]
    >>> t = Tree(3, [Tree(1, [Tree(1), Tree(5)]),
    ...              Tree(4, [Tree(9, [Tree(2)])])])
    >>> widest_level(t)
    [1, 5, 9]
    """
    labels = []
    curr_level = [t]
    while curr_level:
        labels.append([t.label for t in curr_level])
        curr_level = sum([t.branches for t in curr_level], [])
    return max(labels, key=len)

第 3 题：长路径

实现 long_paths，它返回一棵树中所有长度至少为 n 的路径组成的列表。树中的一条路径是一个节点标签组成的列表，从根开始，到叶子结束。后面的每个元素必须来自前一个值对应节点的某个分支的标签。路径的长度是路径中边的条数（即路径中节点数减一）。输出列表中路径的顺序按照它们在树中从左到右的顺序。示例见 doctest。

你的答案
参考答案 
def long_paths(t, n):
    """Return a list of all paths in t with length at least n.

    >>> long_paths(Tree(1), 0)
    [[1]]
    >>> long_paths(Tree(1), 1)
    []
    >>> t = Tree(1, [Tree(2, [Tree(3), Tree(4)]), Tree(5), Tree(6, [Tree(7, [Tree(8)])])])
    >>> print(t)
    1
      2
        3
        4
      5
      6
        7
          8
    >>> for path in long_paths(t, 2):
    ...     print(path)
    ...
    [1, 2, 3]
    [1, 2, 4]
    [1, 6, 7, 8]
    >>> long_paths(t, 3)
    [[1, 6, 7, 8]]
    """
    if n <= 0 and t.is_leaf():
      return [[t.label]]
    paths = []
    for b in t.branches:
      for path in long_paths(b, n - 1):
          paths.append([t.label] + path)
    return paths

修改树

第 4 题：按层修改

提醒一下，节点的深度是指该节点离根有多远。我们把它定义为根与该节点之间的边数。由于根和它自己之间没有边，所以根的深度为 0。

给定一棵树 t 和一个由单参数函数组成的列表 funcs，写一个函数，用 funcs 中对应深度的函数来修改 t 的标签。例如，根节点（深度为 0）的标签会用索引 0 处的函数，也就是 funcs[0] 来修改。假设 funcs 中的所有函数都能接收一个标签值并返回一个合法的标签值。

如果 t 是叶子，而 funcs 中有多于 1 个函数，则应按顺序把剩余的所有函数都作用到 t 的标签上。（示例见 doctest。）如果 funcs 为空，树应保持不变。

你的答案
参考答案 
def level_mutation(t, funcs):
    """Mutates t using the functions in the list funcs.

    >>> t = Tree(1, [Tree(2, [Tree(3)])])
    >>> funcs = [lambda x: x + 1, lambda y: y * 5, lambda z: z ** 2]
    >>> level_mutation(t, funcs)
    >>> t                               # funcs[0] was applied to the label 1, funcs[1] to the label 2, etc.
    Tree(2, [Tree(10, [Tree(9)])])
    >>> t2 = Tree(1, [Tree(2), Tree(3, [Tree(4)])])
    >>> level_mutation(t2, funcs)
    >>> t2                              # (2 * 5) ** 2 = 100
    Tree(2, [Tree(100), Tree(15, [Tree(16)])])
    >>> t3 = Tree(1, [Tree(2)])
    >>> level_mutation(t3, funcs)
    >>> t3
    Tree(2, [Tree(100)])
    """
    if not funcs:
        return
    t.label = funcs[0](t.label)
    remaining = funcs[1:]
    if t.is_leaf() and remaining:
        for f in remaining:
            t.label = f(t.label)
    for b in t.branches:
        level_mutation(b, remaining)

第 5 题：删除

实现 delete，它接收一棵树 t，并删除所有标签为 x 的非根节点。每个剩余节点的父节点是它最近的、未被删除的祖先。换句话说，当一个非叶子节点被删除时，被删除节点的孩子会成为它父节点的孩子。根节点永远不会被删除，即使它的标签是 x。

你的答案
参考答案 
def delete(t, x):
    """Remove all nodes labeled x below the root within Tree t. When a non-leaf
    node is deleted, the deleted node's children become children of its parent.

    The root node will never be removed.

    >>> t = Tree(3, [Tree(2, [Tree(2), Tree(2)]), Tree(2), Tree(2, [Tree(2, [Tree(2), Tree(2)])])])
    >>> delete(t, 2)
    >>> t
    Tree(3)
    >>> t = Tree(1, [Tree(2, [Tree(4, [Tree(2)]), Tree(5)]), Tree(3, [Tree(6), Tree(2)]), Tree(4)])
    >>> delete(t, 2)
    >>> t
    Tree(1, [Tree(4), Tree(5), Tree(3, [Tree(6)]), Tree(4)])
    >>> t = Tree(1, [Tree(2, [Tree(4), Tree(5)]), Tree(3, [Tree(6), Tree(2)]), Tree(2, [Tree(6),  Tree(2), Tree(7), Tree(8)]), Tree(4)])
    >>> delete(t, 2)
    >>> t
    Tree(1, [Tree(4), Tree(5), Tree(3, [Tree(6)]), Tree(6), Tree(7), Tree(8), Tree(4)])
    """
    new_branches = []
    for b in t.branches:
        delete(b, x)
        if b.label == x:
            new_branches.extend(b.branches)
        else:
            new_branches.append(b)
    t.branches = new_branches
