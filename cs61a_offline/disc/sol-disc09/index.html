讨论课 9：Scheme、Scheme 列表

Scheme

你可以用 scheme.cs61a.org 来动手试一试。

一个 if 表达式有 3 个子表达式：

  • 第一个称为谓词（predicate），它总会被求值，用来在另外两个之间做选择。
  • 第二个称为推论（consequent），当谓词的值为真时对它求值。
  • 第三个称为替代（alternative），当谓词的值为假时对它求值。

第二个或第三个表达式（哪个被求值就是哪个）的值，就是整个 if 表达式的值。

在 Scheme 中，只有 #f 是 假值。其他所有值都是真值，包括 #t。

逻辑特殊形式 and 和 or 可以有任意数量的子表达式。用 and 检查它的所有子表达式是否都是真值，用 or 检查是否至少有一个是真值。

一个例子：

scm> (define y (+ 1 2))  ; y is now 3
y
scm> (define z (or (> y 4) (> y 5) (< y 5)))  ; z is true because y < 5
z
scm> (+ 7 (if (and (> y 1) z) y 1))  ; the if expression evaluates to 3
10

expect 形式内建于 scheme.cs61a.org 中，它检查第一个子表达式的求值结果是否等于第二个子表达式。它用于测试。

第 1 题：完美匹配

定义：完全平方数是指某个整数 k 的 k*k。

实现 fit，它接收非负整数 total 和 n。它返回是否存在 n 个不同的正完全平方数之和等于 total。

用 (or _ _) 特殊形式把两个递归调用结合起来：一个在和中使用 k*k，另一个不使用。
你的答案
参考答案 
;;; Return whether there are n perfect squares with no repeats that sum to total
;;;
;;; scm> (fit 10 2)
;;; #t
;;; scm> (fit 9 2)
;;; #f
(define (fit total n)
    (define (f total n k)
        (if (and (= n 0) (= total 0))
            #t
        (if (< total (* k k))
            #f
            (or (f total n (+ k 1)) (f (- total (* k k)) (- n 1) (+ k 1)))
        )))
    (f total n 1))

(expect (fit 10 2) #t)  ; 1*1 + 3*3
(expect (fit 9 1)  #t)  ; 3*3
(expect (fit 9 2)  #f)  ;
(expect (fit 9 3)  #f)  ; 1*1 + 2*2 + 2*2 doesn't count because of repeated 2*2
(expect (fit 25 1)  #t) ; 5*5
(expect (fit 25 2)  #t) ; 3*3 + 4*4
这是一个树递归问题。你的实现应当尝试用不同的方式把 n 个不同的完全平方数相加，看和是否等于 total。对于例子 (fit 10 2)，调用 (f 10 2 1) 返回是否存在 2 个完全平方数之和为 10，且每个都不小于 1*1。要弄清楚这一点，你需要进行两个递归调用：
  • (f 10 2 2)，它返回是否存在 2 个完全平方数之和为 10，且每个都不小于 2*2（不行）
  • (f 9 1 2)，它返回是否存在 1 个完全平方数之和为 9，且不小于 2*2（可以：3*3）

一旦你的实现完成了这两个递归调用，就需要把它们合并成一个结果。

第一个递归调用应当从 total 中减去 k*k，并从 n 中减去 1；另一个递归调用则应保持 total 和 n 不变。

第 2 题：最大公约数

最大公约数（GCD）是能同时整除两个正整数的最大整数。

编写过程 gcd，它使用欧几里得算法计算 a 和 b 的 GCD，该算法递归地利用这样一个事实：两个值的 GCD 是以下两者之一：

  • 如果较小的值能整除较大的值，那就是较小的那个值，或者
  • 较小的值与「较大的值除以较小的值所得的余数」的最大公约数

换句话说，如果 a 大于 b 且 a 不能被 b 整除，那么

gcd(a, b) = gcd(b, a % b)  # please note that this is Python syntax

你可能会觉得提供的过程 min 和 max 很有用。你也可以使用内置的 modulo 和 zero? 过程。

>scm> (modulo 10 4)
>2
>scm> (zero? (- 3 3))
>#t
>scm> (zero? 3)
>#f
你的答案
解答 (define (max a b) (if (> a b) a b)) (define (min a b) (if (> a b) b a)) (define (gcd a b) 
(cond ((zero? a) b)
      ((zero? b) a)
      ((= (modulo (max a b) (min a b)) 0) (min a b))
      (else (gcd (min a b) (modulo (max a b) (min a b)))))

)

(expect (gcd 0 4) 4) (expect (gcd 10 0) 10) (expect (gcd 30 5) 5) (expect (gcd 24 60) 12) (expect (gcd 1071 462) 21)

Scheme 列表 & 引用

Scheme 列表就是链表。快速复习：

  • nil 和 () 是同一个东西：空列表。
  • (cons first rest) 构造一个链表，以 first 作为它的第一个元素，以 rest 作为列表的其余部分，rest 应当始终是一个列表。
  • (car s) 返回列表 s 的第一个元素。
  • (cdr s) 返回列表 s 的其余部分。
  • (list ...) 接收 n 个参数，返回一个长度为 n、以这些参数为元素的列表。
  • (append ...) 接收 n 个列表作为参数，返回一个包含这些列表所有元素的列表。
  • (draw s) 会画出列表 s 的链表结构。它只对 code.cs61a.org/scheme 有效。现在就用类似 (draw (cons 1 nil)) 的写法试一试吧。

引用一个表达式会让它不被求值。例子：

  • 'four 和 (quote four) 都求值为符号 four。
  • '(2 3 4) 和 (quote (2 3 4)) 都求值为一个包含三个元素 2、3、4 的列表。
  • '(2 3 four) 和 (quote (2 3 four)) 求值为一个包含 2、3 和符号 four 的列表。

list 和引用之间有一个重要区别：

scm> (list 2 (+ 3 4))
(2 7)
scm> '(2 (+ 3 4))
(2 (+ 3 4))

第 3 题：删除

实现过程 remove，它接收一个由数字组成的列表 s 和一个数字 x。它返回一个把 s 中所有 x 都删除后的列表。你可以假设 s 中只包含数字，且没有嵌套列表。

你的答案
参考答案 
;;; Return a list with all numbers equal to x removed
;;;
;;; scm> (remove '(3 4 3 4 4 3) 3)
;;; (4 4 4)
;;; scm> (remove '(3 4 3 4 4 3) 4)
;;; (3 3 3)
(define (remove s x)
  (if (null? s) nil
    (if (equal? x (car s)) (remove (cdr s) x) (cons (car s) (remove (cdr s) x)))

))

(expect (remove '(3 4 3 4 4 3) 3) (4 4 4))
(expect (remove '(3 4 3 4 4 3) 4) (3 3 3))

第 4 题：配对

实现 pair-up，它接收一个列表 s。它返回一个由若干列表组成的列表，这些列表按顺序合起来包含 s 的所有元素。结果中的每个列表应有 2 个元素。最后一个最多可以有 3 个。

看看这些例子，确保你理解这个过程在做什么。

你的答案
参考答案 
;;; Return a list of pairs containing the elements of s.
;;;
;;; scm> (pair-up '(3 4 5 6 7 8))
;;; ((3 4) (5 6) (7 8))
;;; scm> (pair-up '(3 4 5 6 7 8 9))
;;; ((3 4) (5 6) (7 8 9))
(define (pair-up s)
    (if (<= (length s) 3)
        (list s)
        (cons (list (car s) (car (cdr s))) (pair-up (cdr (cdr s))))
    ))

(expect (pair-up '(3 4 5 6 7 8)) ((3 4) (5 6) (7 8)) )
(expect (pair-up '(3 4 5 6 7 8 9)) ((3 4) (5 6) (7 8 9)) )

pair-up 接收一个（数字）列表并返回一个列表的列表，所以当 (length s) 小于或等于 3 时，返回一个只包含列表 s 的列表。例如，(pair-up (list 2 3 4)) 应当返回 ((2 3 4))。

用 (cons _ (pair-up _)) 来构造结果，其中 cons 的第一个参数是一个含两个元素的列表：(car s) 和 (car (cdr s))。传给 pair-up 的参数是前两个元素之后的所有内容。

    (define (insert element lst index)

第 6 题：递增的 rope

定义：Scheme 中的 rope 是一个非空列表，其中除最后一个元素外只包含数字，最后一个元素可以是数字，也可以是一个 rope。

实现 up，它是一个 Scheme 过程，接收正整数 n。它返回一个包含 n 的各位数字的 rope，并且是使同一列表中每对相邻数字都按递增顺序排列的最短 rope。

提醒：quotient 过程执行向下取整的除法，就像 Python 中的 //。remainder 过程类似 Python 中的 %。

你的答案
参考答案 
(define (up n)
    (define (helper n result)
        (define first (remainder n 10))  ; Using first will shorten your code
        (if (zero? n) result
            (helper
                (quotient n 10)
                (if (< first (car result))
                    (cons first result)
                    (list first result))
                )))
    (helper
      (quotient n 10)
      (list (remainder n 10))
    ))

(expect (up 314152667899) (3 (1 4 (1 5 (2 6 (6 7 8 9 (9)))))))
把 first 与 (car result) 比较，来决定是把 first cons 到 result 上，还是构造一个以 first 和 result 为元素的新列表。
要在 up 中正确地调用 helper，先构造一个只包含 n 的最后一位数字的 rope：(remainder n 10)。
