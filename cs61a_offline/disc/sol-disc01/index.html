while 与 if

学会使用 if 和 while 是一项基本技能。在本次讨论课中，请专注于我们前三次课学过的内容：if、while、赋值（=）、比较（<、>、==）以及算术运算。请不要使用课堂上还没有讲过的 Python 特性，例如 for、range 和列表。课程后期我们会有充足的时间学习这些内容，而现在正是练习使用 if（教材第 1.5.4 节）和 while（教材第 1.5.5 节）的时候。

问题求解

实现函数的一个有用方法是：

  1. 选一个示例输入和对应的输出。
  2. 用英语描述一个过程，说明如何用简单的步骤从输入算出输出。
  3. 想出执行这个过程还需要哪些额外的名字。
  4. 用这些额外的名字把这个过程用代码实现出来。
  5. 判断这个实现是否真的能在你最初的例子上正常工作。
  6. 判断这个实现是否也能在其他例子上正常工作。（如果不能，你可能需要修改第 2 步。）

重要的是，这种方法并不是读完题目就直接写代码。

例如，在下一页的 is_prime 问题中，你可以：

  1. 选择 n 为 9 作为输入，False 作为输出。
  2. 过程是这样的：检查 9（n）不是 1 到 9（n）之间任何整数的倍数。
  3. 引入 i 来表示 1 到 9（n）之间的每个数。
  4. 实现 is_prime（这一部分由你和你的小组一起完成）。
  5. 通过在心里推演代码的执行过程，检查 is_prime(9) 会返回 False。
  6. 检查 is_prime(3) 会返回 True，is_prime(1) 会返回 False。

Q1：是否为质数？

写一个函数：如果正整数 n 是质数就返回 True，否则返回 False。

质数 n 是指除了 1 和 n 本身之外不能被任何数整除的数。例如，13 是质数，因为它只能被 1 和 13 整除；而 14 不是，因为它能被 1、2、7 和 14 整除。

使用 % 运算符：x % y 返回 x 除以 y 的余数。

你的答案
参考答案 
def is_prime(n):
    """
    >>> is_prime(2)
    True
    >>> is_prime(7)
    True
    >>> is_prime(9)
    False
    >>> is_prime(1) # one is not a prime number!!
    False
    """
    if n == 1:
        return False
    k = 2
    while k < n:
        if n % k == 0:
            return False
        k += 1
    return True

Q2：Fizzbuzz

实现经典的 Fizz Buzz sequence。fizzbuzz 函数接收一个正整数 n，并为从 1 到 n 的每个整数打印一行。对于每个 i：

  • 如果 i 同时能被 3 和 5 整除，打印 fizzbuzz。
  • 如果 i 能被 3 整除（但不能被 5 整除），打印 fizz。
  • 如果 i 能被 5 整除（但不能被 3 整除），打印 buzz。
  • 否则，打印数字 i。

尽量让 fizzbuzz 的实现简洁。

你的答案
参考答案 
def fizzbuzz(n):
    """
    >>> result = fizzbuzz(16)
    1
    2
    fizz
    4
    buzz
    fizz
    7
    8
    fizz
    buzz
    11
    fizz
    13
    14
    fizzbuzz
    16
    >>> print(result)
    None
    """
    i = 1
    while i <= n:
        if i % 3 == 0 and i % 5 == 0:
            print('fizzbuzz')
        elif i % 3 == 0:
            print('fizz')
        elif i % 5 == 0:
            print('buzz')
        else:
            print(i)
        i += 1

Q3：有序数字

实现函数 ordered_digits，它接受一个正整数作为输入：如果从左到右读它的各位数字是非递减的，就返回 True，否则返回 False。例如，5、11、127、1357 的各位数字是有序的，而 21 和 1375 的不是。

你的答案
参考答案 
def ordered_digits(x):
    """Return True if the (base 10) digits of X>0 are in non-decreasing
    order, and False otherwise.

    >>> ordered_digits(5)
    True
    >>> ordered_digits(11)
    True
    >>> ordered_digits(127)
    True
    >>> ordered_digits(1357)
    True
    >>> ordered_digits(21)
    False
    >>> result = ordered_digits(1375) # Return, don't print
    >>> result
    False
    """
    last = x % 10
    x = x // 10
    while x > 0:
        if last < x % 10:
            return False
        last = x % 10
        x = x // 10
    return True

我们依次从右往左分离出每一位数字，并把它与我们上一次分离出的数字（也就是紧挨在它右边的那一位）进行比较。当数字用尽，或者发现某位数字不符合顺序时，我们就停止。

Q4：不重复的数字

写一个函数，返回一个正整数中不同数字的个数。

提示：你可以用 // 和 % 把正整数拆成它的个位数字和其余数字。

你可能发现，先定义一个函数 has_digit(n, k) 会很有帮助，它判断数 n 中是否含有数字 k。

你的答案
参考答案 
def unique_digits(n):
    """Return the number of unique digits in positive integer n.

    >>> unique_digits(8675309) # All are unique
    7
    >>> unique_digits(13173131) # 1, 3, and 7
    3
    >>> unique_digits(101) # 0 and 1
    2
    """
    unique = 0
    while n > 0:
        last = n % 10
        n = n // 10
        if not has_digit(n, last):
            unique += 1
    return unique

# Alternate solution
def unique_digits_alt(n):
    unique = 0
    i = 0
    while i < 10:
        if has_digit(n, i):
            unique += 1
        i += 1
    return unique





def has_digit(n, k):
    """Returns whether k is a digit in n.

    >>> has_digit(10, 1)
    True
    >>> has_digit(12, 7)
    False
    """
    assert k >= 0 and k < 10
    while n > 0:
        last = n % 10
        n = n // 10
        if last == k:
            return True
    return False

我们提供了两种解法：

  • 在一种解法中，我们查看当前这一位数字，然后检查数字的其余部分中是否包含这个数字。只有当这个数字不在其余部分中出现时，我们才说它是唯一的。我们对每一位数字都这样做。
  • 在另一种解法中，我们遍历 0-9 这些数字，对每一个都调用 has_digit。如果它返回 true，我们就知道整个数字中包含该数字，于是把唯一数字的计数加一。

Q5：重复序列

定义：如果正整数 n 是由正整数 m 的数字重复一次或多次写成的，就称 n 是 m 的重复序列。例如，616161 是 61 的重复序列，但 61616 不是。

实现 repeating，它接受正整数 t 和 n，返回 n 是否是某个 t 位整数的重复序列。

你的答案
参考答案 
def repeating(t, n):
    """Return whether t digits repeat to form positive integer n.

    >>> repeating(1, 6161)
    False
    >>> repeating(2, 6161)  # repeats 61 (2 digits)
    True
    >>> repeating(3, 6161)
    False
    >>> repeating(4, 6161)  # repeats 6161 (4 digits)
    True
    >>> repeating(5, 6161)  # there are only 4 digits
    False
    """
    if pow(10, t-1) > n:  # make sure n has at least t digits
        return False
    end = n % pow(10, t)
    rest = n
    while rest:
        if rest % pow(10, t) != end:
           return False
        rest = rest // pow(10, t)
    return True
实现这个函数所需的迭代过程是：检查 rest 的最后 t 位数字是否与 n 的最后 t 位数字相同，然后去掉 rest 的最后 t 位。
