解释器

解释器是一个程序，它让你能用某种语言与计算机交互。它理解你用该语言输入的表达式，并以某种方式执行相应的操作，通常借助一种底层语言。

谈到解释器时，涉及两种语言：

  1. 被解释/被实现的语言。
  2. 底层实现语言。

许多解释器使用「读取-求值-打印循环」（REPL）。这个循环等待用户输入，然后分三步处理它：

  • Read（读取）：解释器接收用户输入（一个字符串），把用户输入的字符串切分成小块（token），然后把这些 token 组织成数据结构。
  • Eval（求值）：eval 与 apply 相互递归，对表达式求值得到一个值。

表示列表

Scheme 调用表达式是一个 Scheme 列表，在 Python 中用一个 Link 实例表示。

例如，调用表达式 (+ (* 3 4) 5) 表示为：

Link('+', Link(Link('*', Link(3, Link(4, nil))), Link(5, nil)))

那些 nil 是可选的，因为 nil 就是 Link.empty，它是 Link 类 __init__ 方法的默认第二个参数。

Link('+', Link(Link('*', Link(3, Link(4))), Link(5)))

Link 类和 nil 对象定义在 Scheme 项目 的 link.py 中。

class Link:
    "A Scheme list is a Link in which rest is a Link or nil."
    empty = ()
    def __init__(self, first, rest=empty):
        self.first = first
        self.rest = rest

    ... # There are also __str__, __repr__, and map methods, omitted here.

nil = Link.empty

求值

第 1 题：求值

在 x 绑定为 -2 的环境中，对 (if (< x 0) (- x) (if (= x -2) 100 y)) 调用 scheme_eval 时，下列哪些内容会被求值？选出所有符合的。（假设 <、- 和 = 都使用默认值。）

  • if
  • <
  • =
  • x
  • y
  • 0
  • -2
  • 100
  • -
  • (
  • )
会被求值的是：<、x、0 和 -。表达式 (if (= x -2) 100 y) 中没有任何内容会被求值，因为最初的判断条件求值为 #t，所以它求值的是推论中的表达式，即 (- x)。此外，if 不会被求值，因为它是特殊形式，而不是调用表达式的运算符。

要用 Project 4 解释器对表达式 (+ (* 3 4) 5) 求值，会按以下顺序对下列表达式调用 scheme_eval：

  1. (+ (* 3 4) 5)
  2. +
  3. (* 3 4)
  4. *
  5. 3
  6. 4
  7. 5

* 会被求值，因为它是 (* 3 4) 的运算符子表达式，而 (* 3 4) 又是 (+ (* 3 4) 5) 的操作数子表达式。

if 表达式也是一个 Scheme 列表，用一个 Link 实例表示。

例如，(if (< x 0) (- x) x) 表示为：

Link('if', Link(Link('<', Link('x', Link(0, nil))), Link(Link('-', Link('x', nil)), Link('x', nil))))

符号 if 不会被求值，因为它是特殊形式的开头，而不是 调用表达式的一部分。引入特殊形式的符号（and、 if、lambda 等）永远不会被求值。

符号 - 不会被求值，它所在的整个子表达式 (- x) 也 不会被求值，因为 (< x 0) 求值为 #f。如果你仍然不确定 为什么有些部分会被求值、有些不会被求值，请问课程助教。

Q2：打印被求值的表达式

定义 print_evals，它接收一个只包含数字、+、* 和括号的 Scheme 表达式 expr。它会打印在对 expr 求值的过程中被求值的所有表达式，打印顺序与它们被传给 scheme_eval 的顺序相同。

注意：对 Link 实例调用 print 会打印它所表示的 Scheme 表达式。

>>> print(Link('+', Link(Link('*', Link(3, Link(4, nil))), Link(5, nil))))
(+ (* 3 4) 5)
你的答案
参考答案 
def print_evals(expr):
    """Print the expressions that are evaluated while evaluating expr.
    expr: a Scheme expression containing only (, ), +, *, and numbers.
    >>> nested_expr = Link('+', Link(Link('*', Link(3, Link(4, nil))), Link(5, nil)))
    >>> print_evals(nested_expr)
    (+ (* 3 4) 5)
    +
    (* 3 4)
    *
    3
    4
    5
    >>> print_evals(Link('*', Link(6, Link(7, Link(nested_expr, Link(8, nil))))))
    (* 6 7 (+ (* 3 4) 5) 8)
    *
    6
    7
    (+ (* 3 4) 5)
    +
    (* 3 4)
    *
    3
    4
    5
    8
    """
    if not isinstance(expr, Link):
        print(expr)

    else:
        print(expr)
        while expr is not nil:
            print_evals(expr.first)
            expr = expr.rest

宏！

宏是一种代码变换，用 define-macro 创建，并通过调用表达式来应用。宏调用的求值过程是：

  1. 把宏的形式参数绑定到宏调用中尚未求值的操作数表达式上。
  2. 对宏的主体求值，它返回一个表达式。
  3. 在原始宏调用的环境中，对宏返回的表达式求值。
scm> (define-macro (twice expr) (list 'begin expr expr))
twice
scm> (twice (+ 2 2))  ; evaluates (begin (+ 2 2) (+ 2 2))
4
scm> (twice (print (+ 2 2)))  ; evaluates (begin (print (+ 2 2)) (print (+ 2 2)))
4
4

Q3：神秘宏

弄清楚这个 mystery-macro 是做什么的。试着阅读代码，并和小组一起讨论示例，来描述它的作用。

(define-macro (mystery-macro expr old new)
    (mystery-helper expr old new))

(define (mystery-helper e o n)
  (if (and (list? e) (not (null? e)))
      (cons (mystery-helper (car e) o n) (mystery-helper (cdr e) o n))
      (if (eq? e o) n e)))
下面是一些 mystery-macro 的用法示例，可以帮助你理解它的作用以及它可能怎么用。 
scm> (define five 5)
five
scm> (mystery-macro (* x x) x five)
25
scm> (mystery-macro (* x x) x (+ five 1))
36
scm> (mystery-macro '(* x x) x y)
(* y y)
scm> (mystery-macro (> (x) (> (y) (+ x y))) > lambda)
(lambda (x) (lambda (y) (+ x y)))
scm> (mystery-macro (begin e e e) e (print five))
5
5
5
mystery-macro 会在对表达式 expr 求值之前，把某个旧符号的所有出现位置替换成新的表达式。

Q4：参数重复器

首先，编写过程 repeater，它接收表达式 expr 和一个非负整数 k，输出一个把 expr 重复 k 次的新列表。

然后编写宏 arg-repeater，它接收一个函数 fn、一个表达式 expr 和一个非负整数 k，其中 k 对应 fn 接收的参数个数。arg-repeater 会把 expr 的 k 个副本传给对 fn 的调用。

注意：框架代码只是一个建议；如果你愿意，可以随意使用自己的结构。

你的答案
参考答案 
(define (repeater expr k)
  ; Returns a list with k copies of expr
  (if (= 0 k)
      nil
      (cons expr (repeater expr (- k 1)))))

(expect (repeater 2 0) ())
(expect (repeater 2 5) (2 2 2 2 2))

(define-macro (arg-repeater fn expr k)
  ; Fills in fn with k copies of expr
  (cons fn (repeater expr k)))

(define (add-four a b c d) (+ a b c d))
(define (mult-one x) x)
(define (mult-seven a1 a2 a3 a4 a5 a6 a7)
  (* a1 a2 a3 a4 a5 a6 a7))

(expect (arg-repeater add-four 10 4) 40)
(expect (arg-repeater mult-one -2 1) -2)
; 2 multiplied to itself 7 times = 2^7 = 128
(expect (arg-repeater mult-seven 2 7) 128)

Q5：反转

编写一个尾递归函数 reverse，它接收一个 Scheme 列表 a，返回反转后的副本。 

scm> (reverse '(1 2 3))
(3 2 1)
scm> (reverse '(0 9 1 2))
(2 1 9 0)
你的答案
参考答案 
(define (reverse lst)
  (define (reverse-tail sofar rest)
    (if (null? rest)
          sofar
          (reverse-tail (cons (car rest) sofar) (cdr rest))))
  (reverse-tail nil lst)
)

(expect (reverse '(1 2 3)) (3 2 1))
(expect (reverse '(0 9 1 2)) (2 1 9 0))

Q6：切片！

实现过程 get-slicer，它接收整数 a 和 b，返回一个 a-b 切片函数。a-b 切片函数接收一个列表作为输入，输出一个新列表，其中包含原列表从索引 a（含）到索引 b（不含）的值。

你的实现应该表现得像 Python 切片，但要假设步长为 1，并且不使用负的切片索引。索引从 0 开始。

注意：框架代码只是一个建议。如果你愿意，可以随意使用自己的结构。

你的答案
参考答案 
(define (get-slicer a b)
  (define (slicer lst)
    (define (slicer-helper c i j)
      (cond 
        ((or (null? c) (<= j i)) nil)
        ((= i 0) (cons (car c) (slicer-helper (cdr c) i (- j 1))))
        (else (slicer-helper (cdr c) (- i 1) (- j 1)))))
    (slicer-helper lst a b))
  slicer)

; DOCTESTS (No need to modify)
(define a '(0 1 2 3 4 5 6))
(define one-two-three (get-slicer 1 4))
(define one-end (get-slicer 1 10))
(define zero (get-slicer 0 1))
(define empty (get-slicer 4 4))

(expect (one-two-three a) (1 2 3))
(expect (one-end a) (1 2 3 4 5 6))
(expect (zero a) (0))
(expect (empty a) ())
