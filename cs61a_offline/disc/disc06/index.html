面向对象编程

面向对象编程（OOP）是一种编程范式，它允许我们把数据当作对象来处理，就像现实生活中的做法一样。

例如，考虑 Student 类。你们每个人都是这个类的一个实例。

所有 AHUT_1A 学生都具备的信息（比如 name）称为实例变量。每个学生都有这些变量，但它们的值因人而异。所有 Student 实例共享的变量称为类变量。例如，extension_days 属性就是一个类变量，因为它是所有学生共有的属性。

所有学生都能做作业、上课、去答疑时间。当函数属于某个特定对象时，它们被称为方法。在这里，这些行为就是 Student 对象的方法。

下面是上面讨论内容的回顾：

  • class（类）：用于创建对象的模板
  • instance（实例）：由某个类创建出来的单个对象
  • instance variable（实例变量）：对象的数据属性，属于某个具体实例
  • class variable（类变量）：对象的数据属性，由某个类的所有实例共享
  • method（方法）：绑定函数，可以在某个类的所有实例上调用

实例变量、类变量和方法都被视为对象的属性。

为了避免为相似的类重复定义属性和方法，我们可以写一个基类，让更专门的类继承它。例如，我们可以写一个叫做 Pet 的类，并把 Dog 定义为 Pet 的子类：

class Pet:
    def __init__(self, name, owner):
        self.is_alive = True    # It's alive!!!
        self.name = name
        self.owner = owner
    def eat(self, thing):
        print(self.name + " ate a " + str(thing) + "!")
    def talk(self):
        print(self.name)

class Dog(Pet):
    def talk(self):
        super().talk()
        print('This Dog says woof!')

继承表示两个或多个类之间的层次关系，其中一个类是另一个类更具体的版本：狗是一种宠物。（在面向对象语言中，我们用「is a」来描述这类关系，而不是指 Python 的 is 运算符。）

由于 Dog 继承自 Pet，Dog 类也会继承 Pet 类的方法，因此我们不必重新定义 __init__ 或 eat。但我们希望每只 Dog 都用 Dog 特有的方式说话，所以可以重写 talk 方法。

我们可以用 super() 来表示 self 的超类，并像超类的实例一样访问任何超类方法。例如，Dog 类中的 super().talk() 会调用 Pet 类中的 talk 方法，但传入的 self 是 Dog 实例。

提示：着手定义一个类的好方法是先确定必要的类属性和实例属性。在实现一个类之前，先描述每个属性的类型以及它将如何使用。

第 1 题：键盘

概述：键盘为字母表中的每个字母都有一个按钮。按下按钮时，它通过调用一个输出函数（例如 print）来输出自己的字母。这个字母是大写还是小写，取决于 caps lock 键被按下的次数。

首先，实现 Button 类，它接收一个小写字母（字符串）和一个单参数的输出函数，例如 Button('c', print)。

Button 的 press 方法会在它的 letter 属性上调用它的 output 属性（一个函数）：如果 caps_lock 被按下的次数是奇数，就输出大写，否则输出小写。press 方法还会让 pressed 加一，并返回被按下的键。提示：'hi'.upper() 求值为 'HI'。

其次，实现 Keyboard 类。Keyboard 有一个名为 keys 的字典，其中为 LOWERCASE_LETTERS 中的每个字母保存一个 Button（以该字母为键）。它还有一个已输入字母的列表，其中可能混合着大写和小写字母。

type 方法接收一个只含小写字母的字符串 word。它对 word 中的每个字母调用 keys 中对应 Button 的 press 方法，从而向 Keyboard 的 typed 列表中添加一个字母（根据 caps_lock 决定是小写还是大写）。重要：在实现 type 时不要使用 upper 或 letter，只调用 press。实现 type 时也不要使用 append；你只能通过 press 来修改 typed 列表。

阅读 doctest 并讨论：

  • 为什么可以用 .press().press().press() 反复按同一个按钮。
  • 为什么反复按按钮有时只打印在一行，有时却打印多行。
  • 为什么 bored.typed 最后有 10 个元素。
因为 self.letter 始终是小写，所以用 self.letter.upper() 来得到大写版本。
caps_lock 被按下的次数是 self.caps_lock.pressed 或 Button.caps_lock.pressed。
output 属性是一个可以被调用的函数：self.output(self.letter) 或 self.output(self.letter.upper())。你不需要返回结果。
keys 可以用字典推导式创建：self.keys = {c: Button(c, ...) for c in LETTERS}。对 Button 的调用应当接收 c 和一个会向 self.typed 追加内容的输出函数，这样每当这些按钮被按下时，就会向 self.typed 追加一个字母。
对 word 中的每个 w，调用 self.key[w] 的 press 方法。当你调用 press 时，Button 应该已经（在 Keyboard.__init__ 方法中）设置好，会把内容输出到当前 Keyboard 的 typed 列表。

字符串表示

我们已经学过如何用类把数据表示为对象，但有时我们需要对象的字符串表示。我们可以通过在类中定义特殊方法 str 和 repr 来自定义对象的显示方式。

class Penguin():
    def __init__(self, age, name):
        self.age = age
        self.name = name

peng = Penguin(3, 'Peng')

让我们用这个 Penguin 类作为例子！现在，如果我们尝试输出或打印 peng，会得到这样的结果：

>>> peng
<__main__.Penguin object at 0x104cb9c40>
>>> print(peng)
<__main__.Penguin object at 0x104cb9c40>

这并不能告诉我多少关于 peng 的信息！我们用 str 和 repr 来输出更容易理解的表示。

str 是作为对象输出使用的「非正式」表示。当我们对对象调用 print() 或 str()（例如 str(peng) 或 print(peng)）时，输出的就是它。

def __str__(self):
    return self.name + ' is a ' + str(self.age) + ' year old penguin!'
>>> str(peng)
'Peng is a 3 year old penguin!'
>>> print(peng)
Peng is a 3 year old penguin!

repr 返回对象的正式字符串表示，通常对调试很有用，在直接显示对象时出现，例如在解释器中输入 peng。

def __repr__(self):
    return "Penguin(Name=\'" + self.name + "\', age=" + str(self.age)+")"
>>> peng
"Penguin(Name = Peng, Age = 3)"
