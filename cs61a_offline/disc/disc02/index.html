Q6：配对器

实现 match_k，它接收一个整数 k，并返回一个函数。该函数接收一个变量 x，如果 x 中所有相隔 k 位的数字都相同，就返回 True。

例如，match_k(2) 返回一个只接收一个参数的函数，它接收 x，并检查 x 中相隔 2 位的数字是否相同。

在 match_k(2)(1010) 中，x = 1010，从左到右的数字依次是 1、0、1、0。1 == 1 且 0 == 0，所以 match_k(2)(1010) 的结果是 True。

在 match_k(2)(2010) 中，x = 2010，从左到右的数字依次是 2、0、1、0。2 != 1 且 0 == 0，所以 match_k(2)(2010) 的结果是 False。

重要：本题不能使用字符串或索引。

提示：用 10 的幂做整除可以去掉最右边的数字。

在每次迭代中，把最后一位数字与它前面第 k 个位置的数字进行比较。

Q7：起伏（A）

定义。对于非负整数中相邻的两位数字，如果左边的数字比右边的小，就称为一次上升；如果左边的数字比右边的大，就称为一次下降。

例如，61127 有 2 次上升（1 → 2 和 2 → 7）和 1 次下降（6 → 1）。

在本题的所有部分中，你都可以使用下面定义的 sign 函数。

def sign(x):
    if x > 0:
        return 1
    elif x < 0:
        return -1
    else:
        return 0

实现 ramp，它接受一个非负整数 n，返回从左到右读它的各位数字时，上升的次数是否多于下降的次数（见上面的定义）。

Q8：起伏（C）

下面的 process 函数使用 tally 和 result 函数来分析非负整数 n 中所有相邻的数字对。tally 函数会作用在每一对相邻数字上。

def process(n, tally, result):
    """Process all pairs of adjacent digits in N using functions TALLY and RESULT.
    """ 

    while n >= 10:
        tally, result = tally(n % 100 // 10, n % 10)
        n = n // 10
    return result()

实现 ups，它返回两个函数，可以作为 tally 和 result 参数传给 process，使得 process 能计算非负整数 n 是否恰好有 k 次上升。

提示：你可以使用上一页的 sign，以及内置的 max 和 min 函数。

Q9：明智地选择（A）

定义：数字测试是一个函数，它接受一个小于 10 的非负整数，返回 True 或 False。

实现 only，它接受一个非负整数 n 和一个数字测试 t，返回一个非负整数，其中只包含那些使得 t 在被调用时返回 True 的 n 的各位数字。这些数字的顺序应与它们在 n 中的顺序相同。数字 0 没有任何位。你不能使用 str、repr、[、] 或 for。

Q10：明智地选择（B）

实现 every，它接受一个数字测试 t，返回一个函数 digit，digit 接受一个正整数 n。digit 函数返回 t 对 n 的每一位数字是否都返回 True。
