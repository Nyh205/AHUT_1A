高阶函数

Q1：配对

实现 match_k，它接收一个整数 k，并返回一个函数。该函数接收一个变量 x，如果 x 中所有相隔 k 位的数字都相同，就返回 True。

例如，match_k(2) 返回一个只接收一个参数的函数，它接收 x，并检查 x 中相隔 2 位的数字是否相同。

在 match_k(2)(1010) 中，x = 1010，从左到右的数字依次是 1、0、1、0。1 == 1 且 0 == 0，所以 match_k(2)(1010) 的结果是 True。

在 match_k(2)(2010) 中，x = 2010，从左到右的数字依次是 2、0、1、0。2 != 1 且 0 == 0，所以 match_k(2)(2010) 的结果是 False。

重要：本题不能使用字符串或索引。

提示：用 10 的幂做整除可以去掉最右边的数字。

迭代器

Q3：连续重复

实现 repeated，它接收一个迭代器 t 和一个大于 1 的整数 k，返回 t 中第一个连续出现 k 次的值。

重要：调用 next 的次数应当尽可能少。假设 t 中一定存在某个元素连续重复至少 k 次。

提示：如果你遇到 StopIteration 异常，说明你的 repeated 函数调用 next 的次数太多了。

链表

Q5：每隔一个

实现 every_other，它接收一个链表 s。它会就地修改 s，把索引为奇数的所有元素（索引从 0 开始）从链表中删除。例如：

>>> s = Link('a', Link('b', Link('c', Link('d'))))
>>> every_other(s)
>>> s.first
'a'
>>> s.rest.first
'c'
>>> s.rest.rest is Link.empty
True

如果 s 中的元素少于两个，s 保持不变。不要返回任何东西！every_other 应当就地修改原链表。

Scheme

Q6：Switch

定义宏 switch，它接收一个表达式 expr 和一个名为 cases 的二元组列表，其中每个二元组的第一个元素是某个数字，第二个元素是一个表达式。switch 会求值 cases 中与 expr 的求值结果相对应的那个数字所在的表达式。

scm> (switch (+ 1 1) ((1 (print 'a))
                      (2 (print 'b))
                      (3 (print 'c))))
b

你可以假设 expr 的求值结果总是一个数字，并且总是 cases 中某个二元组的第一个元素。你还可以假设 cases 中每个二元组的第一个值都是数字，而第二个表达式不包含符号 val。

用 equal? 检查两个数字是否相等。

对于上面展示的例子，构造下面这个表达式： 
(begin
     (define val (+ 1 1))
     (cond ((equal? val 1) (print 'a))
           ((equal? val 2) (print 'b))
           ((equal? val 3) (print 'c))))

这个表达式先把 val 赋值为 3，然后把 val 与 cases 中每个二元组的第一个元素作比较。
