引言

本实验讲解如何配置你的电脑以完成作业，并介绍一些 Python 的基础知识。如果你需要任何帮助，请在 Ed 上发帖，或到你被分配的实验课上寻求帮助。

以下是本实验的提纲：

  • 环境配置（Setup）：配置本课程所需的基本软件。这需要以下几个 组件，列在下面。

    • 安装终端：安装一个终端，以便你与本课程中的文件交互 并运行 OK 命令。
    • 安装 Python 3：在电脑上安装 Python 3.8 或更高版本（最好是 Python 3.11 或更高版本）。
    • 安装文本编辑器：安装用于编辑本课程 .py 文件的 软件。几乎所有学生都使用 VS Code。
  • 复习：你的计算机文件系统 这里概述了计算机文件系统的工作方式，包括绝对路径和相对路径的含义。
  • 演示：使用终端：本部分将带你一步步了解如何使用终端和 Python 解释器。
  • 演示：整理你的文件：本节将带你一步步了解如何使用终端为本课程整理和浏览文件。每个人都应该阅读本节。
  • 必修：完成作业：你必须完成本节才能获得作业学分。本部分的主要目的是让你练习使用我们的软件。
  • 必修：提交作业：把你的作业交上来。
  • 附录：有用的 Python 命令行选项：这些命令对调试你的工作很有帮助，但不是完成实验所必需的。我们收录它们，是因为它们很可能在整个课程中对你都有帮助。

1) Python 会怎么做？（WWPD）

实验作业的其中一项内容，是预测 Python 解释器的行为。我们把这类问题称为“Python 会怎么做？”。

在本课程中，我们使用一个名为 ok 的程序来检验你的掌握情况。每个作业都会附带 ok。下面我们来看看如何用 ok 完成一道 WWPD 题。

打开终端，确保你位于 lab00 目录中，该目录包含本次作业解压后的实验文件。在该目录下输入 ls，确认存在以下文件：

  • lab00.py：本次实验的起始文件
  • ok：我们的测试程序
  • lab00.ok：ok 的配置文件

如果你没有看到这些文件，请使用 cd 导航到正确的目录。

在没有 ok 的目录中尝试运行 ok 会产生错误。

在你的终端中输入以下内容，它会运行 ok 并开始本节内容：

python3 ok -q python-basics -u

命令 python3 ok -q python-basics -u 告诉 Python 解释器运行当前工作目录中名为 ok 的文件。-q python-basics -u 是提供给 ok 程序的输入，用来指明要运行哪一道题。

如环境配置部分所述，如果 python3 命令不起作用，请尝试使用 python 或 py。

系统会提示你输入各个语句/表达式的输出。你必须输入正确才能继续，但答错不会扣分。

第一次运行 ok 时，系统会提示你输入你的 bCourses 邮箱。请按照 这些说明 操作。

>>> x = 20
>>> x + 2
22
>>> x
20
>>> y = 5
>>> y = y + 3
>>> y * 2
16
>>> y + x
28

2) 实现函数

在 VS Code 中打开整个 lab00 文件夹。你可以把文件夹拖拽到 VS Code 应用上，或者打开 VS Code 并使用 File 菜单中的 Open Folder...。打开 lab00 文件夹后，你会在 VS Code 窗口左侧面板的文件资源管理器中看到 lab00.py 文件。点击它开始编辑 lab00.py，这就是你要提交以获得实验学分的文件。

重要：在 VS Code 的 File 菜单中打开 Auto Save。这样，每当你修改文件时，内容都会被保存。如果你没有启用 Auto Save，请务必经常保存你的工作。

推荐：使用 VS Code 内置的终端（菜单中的 Terminal > New Terminal）。如果你按上面的说明在 VS Code 中打开了作业文件夹，那么 VS Code 终端的工作目录就会自动设为该作业文件夹，这意味着你无需切换目录就能检查你的工作。

现在完成实验。你应该会看到一个名为 twenty_twenty_six 的函数，它有一个空白的 return 语句。那个空白是你唯一需要修改的地方。把它替换为一个求值结果为 2026 的表达式。你能想出的最有创意的表达式是什么？

3) 运行测试

我们还会用 ok 来测试你的代码。切换到终端。确保你位于包含 ok 和 lab00.py 的 lab00 目录中。

专业提示：如果你在 VS Code 中打开了 lab00 文件夹，并选择 VS Code 的 Terminal 菜单中的 New Terminal，那么终端会自动位于 lab00 目录中。

现在，用下面这条命令运行 ok 来测试你的代码：

python3 ok

请记住，如果你使用的是 Windows 且 python3 命令不起作用，请尝试只使用 python 或 py。

如果你代码写得正确，并且完成了所有测试的解锁，你应该会看到测试成功：

=====================================================================
Assignment: Lab 0
=====================================================================

~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
Running tests

---------------------------------------------------------------------
Test summary
    2 test cases passed! No cases failed.

如果你没有通过测试，ok 会显示类似这样的内容：

---------------------------------------------------------------------
Doctests for twenty_twenty_six

>>> from lab00 import *
>>> twenty_twenty_six()
0

# Error: expected
#     2026
# but got
#     0

---------------------------------------------------------------------
Test summary
    0 test cases passed before encountering first failed test case

在文本编辑器中修改你的代码，直到测试通过。

每次运行 ok 时，ok 都会尝试备份你的工作。如果它提示 “Connection timed out”，或者提示你未注册该课程，都不必担心。你仍然可以提交这份作业并获得学分。

附录：有用的 Python 命令行选项

  • ls：列出当前目录中的所有文件
  • cd <path to directory>：切换到指定的目录
  • mkdir <directory name>：创建一个具有给定名称的新目录

下面是最常见的几种在文件上运行 Python 的方式。

  1. 不加任何命令行选项会运行你提供的文件中的代码，然后回到命令行。如果你的文件里只有函数定义，那么除非有语法错误，否则不会看到任何输出。

    python3 lab00.py

  2. -i：-i 选项会运行你提供的文件中的代码，然后打开一个交互式会话（提示符为 >>>）。之后你可以对表达式求值，例如调用你定义的函数。要退出，输入 exit()。你也可以使用快捷键：在 Linux/Mac 上是 Ctrl-D，在 Windows 上是 Ctrl-Z 再按 Enter。

    如果你在交互式运行时修改了 Python 文件，需要退出并重新启动解释器，改动才会生效。

    下面这样就能交互式地运行 lab00.py：

    python3 -i lab00.py

  3. -m doctest：运行文件中的 doctest，也就是函数文档字符串里的示例。

    文件中的每个测试都以 >>> 开头，后面跟着一些 Python 代码和期望的输出。

    下面这样就能运行 lab00.py 中的 doctest：

     python3 -m doctest lab00.py

    当代码通过所有 doctest 时，不会显示任何输出；否则会显示失败测试的相关信息。
