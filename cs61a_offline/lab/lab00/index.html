实验 0：开始上手
  • lab00.zip

起始文件

下载 lab00.zip。

简介

本实验讲解如何配置你的电脑以完成作业，并介绍一些 Python 的基础知识。如果你需要帮助，可以查阅课程文档，或与同学一起讨论。

以下是本实验的提纲：

  • 环境配置（Setup）：配置本课程所需的基本软件。这需要下面列出的几个组件。

    • 安装终端（Terminal）：安装一个终端，以便你与本课程中的文件交互并运行 ok 命令。
    • 安装 Python 3：在电脑上安装 Python 3.8 或更高版本（最好是 Python 3.11 或更高版本）。
    • 安装文本编辑器：安装用于编辑本课程 .py 文件的软件。几乎所有学生都用 VS Code。
  • 复习：电脑的文件系统：这是对你电脑文件系统工作原理的概述，包括绝对路径和相对路径的含义。
  • 实操：使用终端：带你熟悉如何使用终端和 Python 解释器。
  • 实操：整理你的文件：这一节带你熟悉如何用终端整理和导航本课程的文件。 每个人都应该阅读这一节。
  • 动手：完成练习：这一节的主要目标是让你练习使用我们的软件。
  • 附录：有用的 Python 命令行选项：这些命令对调试你的工作很有用，但不是完成实验所必需的。我们把它们列出来，因为它们很可能在整个课程中对你有帮助。

你的第一个作业

做作业时，请确保终端的工作目录正确（通常就是你解压作业的目录）。

1) Python 会输出什么？(WWPD)

实验作业的一部分内容是预测 Python 解释器的行为。我们把这类问题称为「Python 会输出什么？」。

在这门课中，我们使用一个叫 ok 的程序来评估你的知识。 每个作业都会附带 ok。下面我们来讲如何用 ok 完成一道 WWPD 题目。

打开终端，确认你在 lab00 目录中——也就是包含本次作业解压后实验文件的目录。在该目录下输入 ls，确认存在以下文件：

  • lab00.py：本实验的起始文件
  • ok：我们的测试程序
  • lab00.ok：ok 的配置文件

如果你没看到这些文件，请用 cd 导航到正确的目录。

在没有 ok 的目录里尝试运行 ok 会报错。

在终端输入以下命令，它会运行 ok 并开始这一节：

python3 ok -q python-basics -u

命令 python3 ok -q python-basics -u 让 Python 解释器运行当前工作目录中名为 ok 的文件。 -q python-basics -u 是传给 ok 程序的输入，用来指定要运行哪道题。

正如环境配置一节所说，如果 python3 命令不起作用，请尝试用 python 或 py。

程序会提示你输入各种语句/表达式的输出。 你必须输入正确才能继续，但答错不会扣分。

第一次运行 ok 时，它会提示你输入邮箱。 请按照这些说明操作。

>>> x = 20
>>> x + 2

______
22

>>> x

______
20

>>> y = 5
>>> y = y + 3
>>> y * 2

______
16

>>> y + x

______
28

2) 实现函数

在 VS Code 中打开整个 lab00 文件夹。你可以把文件夹拖到 VS Code 应用上，或打开 VS Code 后在 File（文件）菜单中使用 Open Folder...（打开文件夹）。 打开 lab00 文件夹后，你会在 VS Code 窗口左侧面板的文件资源管理器中看到 lab00.py 文件。点击它开始编辑 lab00.py——这个文件就是你要提交以获得实验学分的文件。

重要：在 VS Code 的 File（文件）菜单中打开 Auto Save（自动保存）。这样每当你修改文件时，内容就会自动保存。如果你没有启用 Auto Save，请务必经常保存你的工作。

推荐：使用 VS Code 内置的终端（菜单中的 Terminal > New Terminal，即「终端 > 新建终端」）。如果你按上面的说明在 VS Code 中打开了作业文件夹，那么 VS Code 终端的工作目录会自动设置为作业文件夹，这样你就不必再切换目录来检查你的工作了。

现在完成本实验。你应该会看到一个名为 twenty_twenty_six 的函数，它有一个空白的 return 语句。这个空白是你唯一需要修改的地方。 把它替换成一个计算结果为 2026 的表达式。你能想到最有创意的表达式是什么？

3) 运行测试

我们还会用 ok 来测试你的代码。切换到终端，确认你在包含 ok 和 lab00.py 的 lab00 目录中。

小技巧：如果你在 VS Code 中打开了 lab00 文件夹，并在 VS Code 的 Terminal（终端）菜单里选择 New Terminal（新建终端），那么终端会自动处于 lab00 目录中。

现在，用下面的命令运行 ok 来测试你的代码：

python3 ok

请记住，如果你用的是 Windows 且 python3 命令不起作用，请尝试只用 python 或 py。

如果你的代码写对了，并且完成了测试解锁，你应该会看到测试通过：

=====================================================================
Assignment: Lab 0
=====================================================================

~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
Running tests

---------------------------------------------------------------------
Test summary
    2 test cases passed! No cases failed.

如果你没通过测试，ok 会显示类似下面的内容：

---------------------------------------------------------------------
Doctests for twenty_twenty_six

>>> from lab00 import *
>>> twenty_twenty_six()
0

# Error: expected
#     2026
# but got
#     0

---------------------------------------------------------------------
Test summary
    0 test cases passed before encountering first failed test case

在文本编辑器中修改你的代码，直到测试通过。

每次运行 ok 时，ok 都会尝试备份你的工作。如果它提示「连接超时」，不用在意，这不影响你继续练习。

附录：有用的 Python 命令行选项

  • ls：列出当前目录中的所有文件（list）
  • cd <目录路径>：切换到指定的目录（change directory）
  • mkdir <目录名>：用给定名称创建一个新目录（make directory）

以下是在文件上运行 Python 的几种最常见方式。

  1. 不使用任何命令行选项会运行你提供的文件中的代码，然后返回命令行。如果你的文件只包含函数定义，除非有语法错误，否则你不会看到任何输出。

    python3 lab00.py

  2. -i：-i 选项会运行你提供的文件中的代码，然后打开一个交互式会话（带有 >>> 提示符）。你可以计算表达式，例如调用你定义的函数。要退出，输入 exit()。你也可以用键盘快捷键：Linux/Mac 上是 Ctrl-D，Windows 上是 Ctrl-Z Enter。

    如果你在交互式运行时修改了 Python 文件，你需要退出并重启解释器，这些修改才会生效。

    下面是如何交互式运行 lab00.py：

    python3 -i lab00.py

  3. -m doctest：运行文件中的 doctest，也就是函数文档字符串（docstring）中的示例。

    文件中的每个测试都由 >>> 及其后的 Python 代码和期望输出组成。

    下面是如何运行 lab00.py 中的 doctest：

     python3 -m doctest lab00.py

    当我们的代码通过所有 doctest 时，不会显示任何输出。否则，会显示失败测试的相关信息。
