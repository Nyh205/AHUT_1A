重要：如果 python3 命令无法使用，请尝试使用 python 或 py。

下面是最常见的几种在文件上运行 Python 的方式。

  1. 不加任何命令行选项会运行你提供的文件中的代码，然后回到命令行。如果你的文件里只有函数定义，那么除非有语法错误，否则不会看到任何输出。

    python3 lab00.py

  2. -i：-i 选项会运行你提供的文件中的代码，然后打开一个交互式会话（提示符为 >>>）。之后你可以对表达式求值，例如调用你定义的函数。要退出，输入 exit()。你也可以使用快捷键：在 Linux/Mac 上是 Ctrl-D，在 Windows 上是 Ctrl-Z 再按 Enter。

    如果你在交互式运行时修改了 Python 文件，需要退出并重新启动解释器，改动才会生效。

    下面这样就能交互式地运行 lab00.py：

    python3 -i lab00.py

  3. -m doctest：运行文件中的 doctest，也就是函数文档字符串里的示例。

    文件中的每个测试都以 >>> 开头，后面跟着一些 Python 代码和期望的输出。

    下面这样就能运行 lab00.py 中的 doctest：

     python3 -m doctest lab00.py

    当代码通过所有 doctest 时，不会显示任何输出；否则会显示失败测试的相关信息。

使用 % 运算符的一个实用技巧是检查一个数 x 是否能被另一个数 y 整除：

x % y == 0

例如，要检查 x 是否为偶数：x % 2 == 0


你定义的大多数函数都会包含一个 return 语句，它给出用于调用该函数的调用表达式的值。

当 Python 执行 return 语句时，函数调用会立即结束。如果 Python 执行到函数体末尾都没有执行 return 语句，函数会返回 None。

相比之下，print 函数用于显示值。与 return 语句不同，当 Python 对 print 的调用求值时，函数不会立即结束。

def what_prints():
    print('Hello World!')
    return 'Exiting this function.'
    print('This course is awesome!')

>>> what_prints()
Hello World!
'Exiting this function.'

还要注意，print 显示文本时不带引号，而 return 会保留引号。

Q4：下降阶乘

我们来写一个函数 falling，它是一个“下降”阶乘，接收两个参数 n 和 k，返回从 n 开始向下连续的 k 个数的乘积。当 k 为 0 时，函数应返回 1。

def falling(n, k):
    """Compute the falling factorial of n to depth k.

    >>> falling(6, 3)  # 6 * 5 * 4
    120
    >>> falling(4, 3)  # 4 * 3 * 2
    24
    >>> falling(4, 1)  # 4
    4
    >>> falling(4, 0)
    1
    """

    total, stop = 1, n-k
    while n > stop:
        total, n = total*n, n-1
    return total

Q5：能被 k 整除

编写一个函数 divisible_by_k，接收正整数 n 和 k。它按从小到大的顺序打印所有小于等于 n 且能被 k 整除的正整数。然后，它返回打印了多少个数。

def divisible_by_k(n, k):
    """
    >>> a = divisible_by_k(10, 2)  # 2, 4, 6, 8, and 10 are divisible by 2
    2
    4
    6
    8
    10
    >>> a
    5
    >>> b = divisible_by_k(3, 1)  # 1, 2, and 3 are divisible by 1
    1
    2
    3
    >>> b
    3
    >>> c = divisible_by_k(6, 7)  # There are no integers up to 6 that are divisible by 7
    >>> c
    0
    """

    count = 0
    i = 1
    while i <= n:
        if i % k == 0:
            print(i)
            count += 1
        i += 1
    return count

用 ok 测试你的代码：

python3 ok -q divisible_by_k

Q6：两个相邻的 8

编写一个函数，接收一个数并判断它的各位数字中是否含有两个相邻的 8。

def double_eights(n):
    """Return true if n has two eights in a row.
    >>> double_eights(8)
    False
    >>> double_eights(88)
    True
    >>> double_eights(2882)
    True
    >>> double_eights(880088)
    True
    >>> double_eights(12345)
    False
    >>> double_eights(80808080)
    False
    """

    prev_eight = False
    while n > 0:
        last_digit = n % 10
        if last_digit == 8 and prev_eight:
            return True
        elif last_digit == 8:
            prev_eight = True
        else:
            prev_eight = False
        n = n // 10
    return False

# Alternate solution (no unnecessary base case)
def double_eights_alt_e(n):
    if n % 100 == 88:
        return True
    elif n < 100:
        return False
    return double_eights_alt_e(n // 10)

# Alternate solution
def double_eights_alt(n):
    while n:
        if n % 10 == 8 and n // 10 % 10 == 8:
            return True
        n //= 10
    return False

python3 ok -q double_eights

Q8：取某一位数字

实现 digit，它接收正整数 n 和 k，函数体只有一个 return 语句。它返回 n 中位于最右边数字（个位）左边第 k 位上的数字。如果 k 为 0，返回最右边的数字。如果 n 中不存在位于最右边数字左边第 k 位的数字，则返回 0。

提示：使用 // 和 %，以及内置的 pow 函数来取出 n 的某一位数字。

def digit(n, k):
    """Return the k-th digit from the right of n for positive integers n and k.

    >>> digit(3579, 2)
    5
    >>> digit(3579, 0)
    9
    >>> digit(3579, 10)
    0
    """

    return n // pow(10, k) % 10

用 ok 测试你的代码：

python3 ok -q digit

Q9：中间的那个数

实现 middle：只写一个 return 表达式，其求值结果是三个互不相同的整数 a、b、c 中既不是最大也不是最小的那个值。

提示：试着先把所有数组合起来，再用内置的 min 和 max 函数去掉你不想返回的那些数。

>>> max(1, 2, 3)
3
>>> min(-1, -2, -3)
-3
def middle(a, b, c):
    """Return the number among a, b, and c that is not the smallest or largest.
    Assume a, b, and c are all different numbers.

    >>> middle(3, 5, 4)
    4
    >>> middle(30, 5, 4)
    5
    >>> middle(3, 5, 40)
    5
    >>> middle(3, 5, 40)
    5
    >>> middle(30, 5, 40)
    30
    """

    return a + b + c - min(a, b, c) - max(a, b, c)

用 ok 测试你的代码：

python3 ok -q middle

Q10：各位数字之和

编写一个函数，接收一个非负整数并求其各位数字之和。（在这里使用整除和取模可能会很有帮助！）

def sum_digits(y):
    """Sum all the digits of y.

    >>> sum_digits(10) # 1 + 0 = 1
    1
    >>> sum_digits(4224) # 4 + 2 + 2 + 4 = 12
    12
    >>> sum_digits(1234567890)
    45
    >>> a = sum_digits(123) # make sure that you are using return rather than print
    >>> a
    6
    """

    total = 0
    while y > 0:
        total, y = total + y % 10, y // 10
    return total

用 ok 测试你的代码：

python3 ok -q sum_digits
