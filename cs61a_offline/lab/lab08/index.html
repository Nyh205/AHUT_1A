链表

如果你需要复习链表，请查阅下面的折叠内容。你可以直接跳到题目部分，遇到困难时再回来查阅。

链表是一种用于存储值序列的数据结构。在某些操作上，它比内置的普通列表更高效，例如在一个长列表的中间插入一个值。链表不是内置的，因此我们定义了一个名为 Link 的类来表示它。 链表要么是一个 Link 实例，要么是 Link.empty（表示空链表）。

Link 的实例有两个实例属性：first 和 rest。

Link 实例的 rest 属性应始终是一个链表：要么是另一个 Link 实例，要么是 Link.empty。它绝不应为 None。

要判断链表是否为空，可将它与 Link.empty 比较。由于空链表始终只有一个，我们可以用 is 来比较，但用 == 也可以。

def is_empty(s):
    """Return whether linked list s is empty."""
    return s is Link.empty:

你可以用两种方式修改一个 Link 对象 s：

  • 用 s.first = ... 改变第一个元素
  • 用 s.rest = ... 改变其余的元素

你可以通过调用 Link 来创建一个新的 Link 对象：

  • Link(4) 创建一个长度为 1、包含 4 的链表。
  • Link(4, s) 创建一个链表，它以 4 开头，后面跟着链表 s 的元素。

下面是 Link 类的实现：

class Link:
    """A linked list is either a Link object or Link.empty

    >>> s = Link(3, Link(4, Link(5)))
    >>> s.rest
    Link(4, Link(5))
    >>> s.rest.rest.rest is Link.empty
    True
    >>> s.rest.first * 2
    8
    >>> print(s)
    (3 4 5)
    """
    empty = ()

    def __init__(self, first, rest=empty):
        assert rest is Link.empty or isinstance(rest, Link)
        self.first = first
        self.rest = rest

    def __repr__(self):
        if self.rest:
            rest_repr = ', ' + repr(self.rest)
        else:
            rest_repr = ''
        return 'Link(' + repr(self.first) + rest_repr + ')'

    def __str__(self):
        string = '('
        while self.rest is not Link.empty:
            string += str(self.first) + ' '
            self = self.rest
        return string + str(self.first) + ')'
