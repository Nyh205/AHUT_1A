可变的树

Tree 实例有两个实例属性：
  • label 是存储在树根处的值。
  • branches 是一个由 Tree 实例组成的列表，保存了树中其余部分的标签。

Tree 类（省略了 __repr__ 和 __str__ 方法）的定义如下：

class Tree:
    """A tree has a label and a list of branches.

    >>> t = Tree(3, [Tree(2, [Tree(5)]), Tree(4)])
    >>> t.label
    3
    >>> t.branches[0].label
    2
    >>> t.branches[1].is_leaf()
    True
    """
    def __init__(self, label, branches=[]):
        self.label = label
        for branch in branches:
            assert isinstance(branch, Tree)
        self.branches = list(branches)

    def is_leaf(self):
        return not self.branches

要用标签 x（任意值）和分支列表 bs（由 Tree 实例组成的列表）构造一个 Tree 实例并把它命名为 t，可以写 t = Tree(x, bs)。

对于树 t：

  • 它的根标签可以是任意值，t.label 求值的结果就是它。
  • 它的分支总是 Tree 实例，t.branches 求值的结果是它的分支列表。
  • 如果 t.branches 为空，t.is_leaf() 返回 True，否则返回 False。
  • 要构造一个标签为 x 的叶子，写 Tree(x)。

显示一棵树 t：

  • repr(t) 返回一个 Python 表达式，对它求值会得到一棵等价的树。
  • str(t) 为每个标签输出一行，其缩进比它的父节点多一级，子节点显示在父节点下方。
>>> t = Tree(3, [Tree(1, [Tree(4), Tree(1)]), Tree(5, [Tree(9)])])

>>> t         # displays the contents of repr(t)
Tree(3, [Tree(1, [Tree(4), Tree(1)]), Tree(5, [Tree(9)])])

>>> print(t)  # displays the contents of str(t)
3
  1
    4
    1
  5
    9

修改（也就是 mutate）一棵树 t：

  • t.label = y 把 t 的根标签改为 y（任意值）。
  • t.branches = ns 把 t 的分支改为 ns（由 Tree 实例组成的列表）。
  • 修改 t.branches 会改变 t。例如，t.branches.append(Tree(y)) 会把一个标签为 y 的叶子添加为最右边的分支。
  • 修改 t 中任意一个分支都会改变 t。例如，t.branches[0].label = y 会把最左边分支的根标签改为 y。
>>> t.label = 3.0
>>> t.branches[1].label = 5.0
>>> t.branches.append(Tree(2, [Tree(6)]))
>>> print(t)
3.0
  1
    4
    1
  5.0
    9
  2
    6

- 树的构造函数与选择函数 Tree 类
构造树 给定一个标签和一个分支列表来构造一棵树时，我们调用 tree(label, branches) 给定一个标签和一个分支列表来构造一个树对象时，我们调用 Tree(label, branches)（它会调用 Tree.__init__ 方法）。
根标签与分支 要获取树 t 的标签或分支，我们分别调用 label(t) 或 branches(t) 要获取树 t 的标签或分支，我们分别访问实例属性 t.label 或 t.branches。
可变性 函数式的树数据抽象是不可变的（在遵守其抽象屏障的前提下），因为我们无法给调用表达式赋值 Tree 实例的 label 和 branches 属性可以被重新赋值，从而修改这棵树。
判断树是否为叶子 要判断树 t 是否为叶子，我们调用函数 is_leaf(t) 要判断树 t 是否为叶子，我们调用方法 t.is_leaf()。这个方法只能在 Tree 对象上调用。

Q1：删除

实现 delete 函数：它接收一棵树 t，并移除所有标签为 x 的非根节点。每个保留下来的节点的父节点，是它最近的、未被移除的祖先节点。根节点永远不会被移除，即使它的标签是 x。

def delete(t, x):
    """Remove all nodes labeled x below the root within Tree t. When a non-leaf
    node is deleted, the deleted node's children become children of its parent.

    The root node will never be removed.

    >>> t = Tree(3, [Tree(2, [Tree(2), Tree(2)]), Tree(2), Tree(2, [Tree(2, [Tree(2), Tree(2)])])])
    >>> delete(t, 2)
    >>> t
    Tree(3)
    >>> t = Tree(1, [Tree(2, [Tree(4, [Tree(2)]), Tree(5)]), Tree(3, [Tree(6), Tree(2)]), Tree(4)])
    >>> delete(t, 2)
    >>> t
    Tree(1, [Tree(4), Tree(5), Tree(3, [Tree(6)]), Tree(4)])
    >>> t = Tree(1, [Tree(2, [Tree(4), Tree(5)]), Tree(3, [Tree(6), Tree(2)]), Tree(2, [Tree(6),  Tree(2), Tree(7), Tree(8)]), Tree(4)])
    >>> delete(t, 2)
    >>> t
    Tree(1, [Tree(4), Tree(5), Tree(3, [Tree(6)]), Tree(6), Tree(7), Tree(8), Tree(4)])
    """
    new_branches = []

    for b in t.branches:
        delete(b, x)
        if b.label == x:

            new_branches.extend(b.branches)
        else:

            new_branches.append(b)
    t.branches = new_branches

Q2：子序列

序列 s 的子序列是从 s 中取出的一部分元素，且保持它们在 s 中出现的先后顺序。考虑列表 [1, 2, 3]，它的子序列包括 []、[1, 3]、[2] 和 [1, 2, 3]。

编写一个函数，接收一个列表，返回该列表所有可能的子序列。子序列应以列表的列表形式返回，其中每个内层列表都是原始输入的一个子序列。

为此，你可能希望先编写一个函数 insert_into_all：它接收一个元素和一个列表的列表，把该元素添加到每个内层列表的开头，并返回得到的新列表。

def insert_into_all(item, nested_list):
    """Return a new list consisting of all the lists in nested_list,
    but with item added to the front of each. You can assume that
    nested_list is a list of lists.

    >>> nl = [[], [1, 2], [3]]
    >>> insert_into_all(0, nl)
    [[0], [0, 1, 2], [0, 3]]
    """

    return [[item] + lst for lst in nested_list]

def subseqs(s):
    """Return a nested list (a list of lists) of all subsequences of S.
    The subsequences can appear in any order. You can assume S is a list.

    >>> seqs = subseqs([1, 2, 3])
    >>> sorted(seqs)
    [[], [1], [1, 2], [1, 2, 3], [1, 3], [2], [2, 3], [3]]
    >>> subseqs([])
    [[]]
    """

    if not s:
        return [[]]
    else:

        subset = subseqs(s[1:])
        return insert_into_all(s[0], subset) + subset

Q3：非递减子序列

我们要编写一个函数，它接收一个列表，返回一个列表的列表，其中每个列表都是原始输入的一个子序列。

但我们有一个条件：只保留相邻元素非递减的那些子序列。例如，[1, 3, 2] 是 [1, 3, 2, 4] 的子序列，但由于 2 < 3，这个子序列不会出现在我们的结果中。

你可以假设传入的列表 s 中只包含非负元素。

你可以使用辅助函数 insert_into_all。

def insert_into_all(item, lsts):
    """Assuming that lsts is a list of lists, return a new list consisting of
    all the lists in lsts, but with item added to the front of each.

    >>> lsts = [[], [1, 2], [3]]
    >>> insert_into_all(0, lsts)
    [[0], [0, 1, 2], [0, 3]]
    """
    return [[item] + lst for lst in lsts]
def non_decrease_subseqs(s):
    """Return a nested list of all subsequences of S (a list of lists) 
    for which the elements of the subsequence are nondecreasing. The 
    subsequences can appear in any order. You can assume S is a list.

    >>> seqs = non_decrease_subseqs([1, 3, 2])
    >>> sorted(seqs)
    [[], [1], [1, 2], [1, 3], [2], [3]]
    >>> non_decrease_subseqs([])
    [[]]
    >>> seqs2 = non_decrease_subseqs([1, 1, 2])
    >>> sorted(seqs2)
    [[], [1], [1], [1, 1], [1, 1, 2], [1, 2], [1, 2], [2]]
    """
    def subseq_helper(s, prev):
        if not s:

            return [[]]
        elif s[0] < prev:

            return subseq_helper(s[1:], prev)
        else:

            a = subseq_helper(s[1:], s[0])
            b = subseq_helper(s[1:], prev)
            return insert_into_all(s[0], a) + b
    return subseq_helper(s, 0)

Q4：共同队员

实现函数 common_players。common_players 接收一个 roster 字典，该字典把队员映射到他们所属的队伍，并返回一个新的字典，把队伍映射到该队伍中队员的列表。列表中队员名字的顺序无关紧要。

def common_players(roster):
    """Returns a dictionary containing values along with a corresponding
    list of keys that had that value from the original dictionary.
    >>> full_roster = {
    ...     "bob": "Team A",
    ...     "barnum": "Team B",
    ...     "beatrice": "Team C",
    ...     "bernice": "Team B",
    ...     "ben": "Team D",
    ...     "belle": "Team A",
    ...     "bill": "Team B",
    ...     "bernie": "Team B",
    ...     "baxter": "Team A"
    ... }
    >>> player_dict = common_players(full_roster)
    >>> type(player_dict) == dict
    True
    >>> for key, val in sorted(player_dict.items()):
    ...     print(key, list(sorted(val)))
    Team A ['baxter', 'belle', 'bob']
    Team B ['barnum', 'bernice', 'bernie', 'bill']
    Team C ['beatrice']
    Team D ['ben']
    """

    result_dict = {}
    for player in roster:
        team = roster[player]
        if team in result_dict:
            result_dict[team] += [player]
        else:
            result_dict[team] = [player]
    return result_dict

Q5：爬楼梯的方式

假设你想爬上一段有 n 级台阶的楼梯，其中 n 是正整数。你每次可以迈一级或两级台阶。

编写一个生成器函数 stair_ways，产出你爬上这段楼梯的所有不同方式。

每一种爬楼梯的「方式」都可以用一个由 1 和 2 组成的列表来表示，其中每个数字表示你这次是迈一级还是两级台阶。

例如，对于有 3 级台阶的楼梯，共有三种爬法：

  • 每次迈一级：[1, 1, 1]。
  • 先迈两级再迈一级：[2, 1]。
  • 先迈一级再迈两级：[1, 2]。

因此，stair_ways(3) 应该产出 [1, 1, 1]、[2, 1] 和 [1, 2]。它们可以以任意顺序产出。

提示：用递归的思路思考这个问题。如果你站在第 n 级台阶上，那么你刚刚可能是从哪一级台阶过来的？

def stair_ways(n):
    """
    Yield all the ways to climb a set of n stairs taking
    1 or 2 steps at a time.

    >>> list(stair_ways(0))
    [[]]
    >>> s_w = stair_ways(4)
    >>> sorted([next(s_w) for _ in range(5)])
    [[1, 1, 1, 1], [1, 1, 2], [1, 2, 1], [2, 1, 1], [2, 2]]
    >>> list(s_w) # Ensure you're not yielding extra
    []
    """

    if n == 0:
        yield []
    elif n == 1:
        yield [1]
    else:
        for way in stair_ways(n - 1):
            yield [1] + way
        for way in stair_ways(n - 2):
            yield [2] + way

选举游戏

我们来实现一个名为 Election 的游戏。在这个游戏中，两名玩家相互竞争，争取赢得最多的选票。两位玩家一开始都拥有 0 张选票和 100 点人气值。

两位玩家轮流行动，先手是第一位玩家。每一轮，当前玩家选择一个动作。动作有两种类型：

  • 玩家可以发起辩论（debate），从而获得或失去 50 点人气值。如果该玩家的人气值为 p1，另一位玩家的人气值为 p2，那么该玩家获得 50 点人气值的概率是 max(0.1, p1 / (p1 + p2))。注意这里的 max 保证了概率永远不会低于 0.1。
  • 玩家可以发表演讲（speech）。如果该玩家的人气值为 p1，另一位玩家的人气值为 p2，那么该玩家获得 p1 // 10 张选票和人气值，而另一位玩家失去 p2 // 10 点人气值。

当某位玩家达到 50 张选票，或者总共进行了 10 轮（每位玩家各行动 5 轮）时，游戏结束。游戏结束时选票更多的一方获胜！

Q6：Player 类

首先，我们来实现 Player 类。请填写 debate 和 speech 方法，它们接收另一位玩家 other，并按照上面的描述实现正确的行为。另外还有几点需要注意：

  • 每个玩家都带有一个随机数生成器（实例属性 random_func），它是一个不接受参数的函数，调用时返回 0 到 1 之间的随机浮点数。
  • 在 debate 方法中，你应该调用 random_func 函数来获得一个随机数。如果这个随机数小于上面描述的概率，该玩家就获得 50 点人气值，否则失去 50 点人气值。
  • 任何一位玩家的人气值都不应该变成负数。如果出现了负数，就把它设为 0。
### Phase 1: The Player Class
class Player:
    """
    >>> random = make_test_random()
    >>> p1 = Player('Hill', random)
    >>> p2 = Player('Don', random)
    >>> p1.popularity
    100
    >>> p1.debate(p2)  # random() should return 0.0
    >>> p1.popularity
    150
    >>> p2.popularity
    100
    >>> p2.votes
    0
    >>> p2.speech(p1)
    >>> p2.votes
    10
    >>> p2.popularity
    110
    >>> p1.popularity
    135
    >>> p1.speech(p2)
    >>> p1.votes
    13
    >>> p1.popularity
    148
    >>> p2.votes
    10
    >>> p2.popularity
    99
    >>> for _ in range(4):  # 0.1, 0.2, 0.3, 0.4
    ...     p1.debate(p2)
    >>> p2.debate(p1)
    >>> p2.popularity
    49
    >>> p2.debate(p1)
    >>> p2.popularity
    0
    """
    def __init__(self, name, random_func):
        self.name = name
        self.votes = 0
        self.popularity = 100
        self.random_func = random_func

    def debate(self, other):

        prob = max(0.1, self.popularity / (self.popularity + other.popularity))
        if self.random_func() < prob:
            self.popularity += 50
        else:
            self.popularity = max(0, self.popularity - 50)

    def speech(self, other):

        self.votes += self.popularity // 10
        self.popularity += self.popularity // 10
        other.popularity = max(0, other.popularity - (other.popularity // 10))

    def choose(self, other):
        return self.speech

Q7：Game 类

现在，实现 Game 类。请填写 play 方法，它应该让两位玩家轮流行动，从 p1 开始，每人每次进行一轮。Player 类中的 choose 方法返回应该被调用以执行该动作的方法，即 debate 或 speech。

此外，请填写 winner 方法，它应返回选票更多的玩家；如果双方选票相同，则返回 None。

### Phase 2: The Game Class
class Game:
    """
    >>> random = make_test_random()
    >>> p1, p2 = Player('Hill',random), Player('Don', random)
    >>> g = Game(p1, p2)
    >>> winner = g.play()
    >>> p1 is winner
    True
    >>> # Additional correctness tests
    >>> winner is g.winner()
    True
    >>> g.turn
    10
    >>> p1.votes = p2.votes
    >>> print(g.winner())
    None
    """
    def __init__(self, player1, player2):
        self.p1 = player1
        self.p2 = player2
        self.turn = 0

    def play(self):
        while not self.game_over():

            if self.turn % 2 == 0:
                curr, other = self.p1, self.p2
            else:
                curr, other = self.p2, self.p1
            curr.choose(other)(other)
            self.turn += 1
        return self.winner()

    def game_over(self):
        return max(self.p1.votes, self.p2.votes) >= 50 or self.turn >= 10

    def winner(self):

        if self.p1.votes > self.p2.votes:
            return self.p1
        elif self.p2.votes > self.p1.votes:
            return self.p2
        else:
            return None

Q9：两个列表

实现函数 two_list，它接收两个列表并返回一个链表。第一个列表包含我们想要放进链表的各个值，第二个列表包含每个对应值的数量。假设两个列表长度相同且长度至少为 1，并假设第二个列表中的所有元素都大于 0。

def two_list(vals, counts):
    """
    Returns a linked list according to the two lists that were passed in. Assume
    vals and counts are the same size. Elements in vals represent the value, and the
    corresponding element in counts represents the number of this value desired in the
    final linked list. Assume all elements in counts are greater than 0. Assume both
    lists have at least one element.
    >>> a = [1, 3]
    >>> b = [1, 1]
    >>> c = two_list(a, b)
    >>> c
    Link(1, Link(3))
    >>> a = [1, 3, 2]
    >>> b = [2, 2, 1]
    >>> c = two_list(a, b)
    >>> c
    Link(1, Link(1, Link(3, Link(3, Link(2)))))
    """

    def helper(count, index):
        if count == 0:
            if index + 1 == len(vals):
                return Link.empty
            return Link(vals[index + 1], helper(counts[index + 1] - 1, index + 1))
        return Link(vals[index], helper(count - 1, index))
    return helper(counts[0], 0)

#Iterative solution
def two_list_iterative(vals, counts):
    result = Link(None)
    p = result
    for index in range(len(vals)):
        item = vals[index]
        for _ in range(counts[index]):
            p.rest = Link(item)
            p = p.rest
    return result.rest

Q10：accumulate

填写过程 accumulate 的定义，它按照以下参数把前 n 个自然数（即 1 到 n，包含两端）合并起来：

  1. merger：一个接受两个参数的函数
  2. start：我们开始合并时的起始数字
  3. n：要合并的自然数个数
  4. term：一个接受一个参数的函数，用于计算序列的第 n 项

例如，我们可以用乘法运算符作为 merger、以 1 作为乘积的起点，求出 1 到 5 所有数字的乘积：

scm> (define (identity x) x)
scm> (accumulate * 1 5 identity)  ; 1 * 1 * 2 * 3 * 4 * 5
120

我们也可以用加法运算符作为 merger、以 square 作为 term，求出同样这些数字的平方和：

scm> (define (square x) (* x x))
scm> (accumulate + 0 5 square)  ; 0 + 1^2 + 2^2 + 3^2 + 4^2 + 5^2
55
scm> (accumulate + 5 5 square)  ; 5 + 1^2 + 2^2 + 3^2 + 4^2 + 5^2
60

你可以假设 merger 总是可交换的：也就是说，参数的顺序无关紧要。

(define (accumulate merger start n term)

  (if (= n 0)
    start
    (accumulate merger (merger (term n) start) (- n 1) term))
)

用 ok 解锁并测试你的代码：

python3 ok -q accumulate -u
python3 ok -q accumulate

Q11：尾递归 accumulate（可选）

在本次作业的前面部分，你在 Scheme 中实现了 accumulate。提醒一下，accumulate 会按照参数 merger、start、n 和 term 把前 n 个自然数合并起来。

你可以参考你自己实现的 accumulate，回忆这个函数的作用，并复习它的实现方式。

把你实现的 accumulate 改写为尾递归的。它仍然要通过所有针对「普通」accumulate 的测试！

你可以假设输入的 merger 和 term 过程都是正确的尾递归。

如果你在上一题中实现的 accumulate 已经是尾递归的，你可以直接把那个解答抄过来（把 accumulate 相应地替换为 accumulate-tail）。

如果你遇到了 recursion depth exceeded（递归深度超出）错误，而且你使用的是 staff 版解释器，那么很可能是你的解答不是正确的尾递归。

我们通过用一个非常大的输入调用 accumulate-tail 来检验你的解答是否是尾递归的。如果你的解答不是尾递归、并且没有使用常数个环境帧，它将无法成功运行。

(define (accumulate-tail merger start n term)

  (define (accum-helper x so-far)
    (if (= x 0)
      so-far
      (accum-helper (- x 1) (merger (term x) so-far))
    ))
  (accum-helper n start))
; ALT solution
(define (accumulate-tail merger start n term)
  (if (= n 0)
    start
    (accumulate-tail merger (merger (term n) start) (- n 1) term))
)

用 ok 测试你的代码：

python3 ok -q accumulate-tail

如果我们在 Python 中用迭代的方式实现它，可能会是这样：

def accumulate(merger, start, n, term):
    total = start
    while n > 0:
        total = merger(total, term(n))
        n -= 1
    return total

考虑到这一点，我们可以在 Scheme 中创建一个辅助函数，帮助我们跟踪累计的总和。这个值会在每次递归调用中更新。

另一种解法只是用 start 值来追踪我们目前用过的所有值，但它的实际作用是一样的。
