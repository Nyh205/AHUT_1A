短路求值

你觉得如果把下面的内容输入 Python，会发生什么？

1 / 0

在 Python 中试一试吧！你应该会看到一个 ZeroDivisionError。那下面这个表达式呢？

True or 1 / 0

它的求值结果是 True，因为 Python 的 and 和 or 运算符会短路。也就是说，它们不一定会对每个操作数求值。

运算符 检查： 从左到右求值直到： 示例
AND 所有值都为真 第一个假值 False and 1 / 0 的求值结果为 False
OR 至少有一个值为真 第一个真值 True or 1 / 0 的求值结果为 True

当运算符遇到某个操作数、从而能够对表达式得出结论时，就会发生短路。例如，and 一旦遇到第一个假值就会短路，因为它由此知道并非所有值都为真。

如果 and 和 or 没有发生短路，它们就只返回最后一个值；另一种记忆方式是：无论是否短路，and 和 or 总是返回它们最后求值的东西。请记住，当使用的值不是 True 和 False 时，and 和 or 并不总是返回布尔值。

高阶函数

变量是绑定到值的名字，值可以是像 3 或 'Hello World' 这样的基本类型，但也可以是函数。由于函数可以接受任何值作为参数，因此其他函数也可以作为参数传入。这就是高阶函数的基础。

高阶函数是指通过接受函数作为参数、返回一个函数或两者兼有的方式来操作其他函数的函数。我们将在本次实验课中介绍高阶函数的基础知识，并在下一次实验课中探索高阶函数的许多应用。

函数作为参数

在 Python 中，函数对象是可以到处传递的值。我们知道，创建函数的一种方式是使用 def 语句：

def square(x):
    return x * x

上面的语句创建了一个内在名称为 square 的函数对象，并在当前环境中把它绑定到名字 square。现在我们试着把它作为参数传递。

首先，我们来写一个接收另一个函数作为参数的函数：

def scale(f, x, k):
    """ Returns the result of f(x) scaled by k. """
    return k * f(x)

现在我们可以用 square 和其他一些参数来调用 scale 了：

>>> scale(square, 3, 2) # Double square(3)
18
>>> scale(square, 2, 5) # 5 times 2 squared
20

注意，在 scale 调用的函数体中，内在名称为 square 的函数对象被绑定到参数 f。然后，我们在 scale 的函数体中通过调用 f(x) 来调用 square。

正如我们在上面关于 lambda 表达式的一节中所看到的，我们也可以把 lambda 表达式传入调用表达式！

>>> scale(lambda x: x + 10, 5, 2)
30

在这个调用表达式的帧中，名字 f 被绑定到由 lambda 表达式 lambda x: x + 10 创建的函数。

返回函数的函数

因为函数是值，所以它们可以作为返回值！下面是一个例子：

def multiply_by(m):
    def multiply(n):
        return n * m
    return multiply

在这个例子中，我们在 multiply_by 的函数体内定义了函数 multiply，然后把它返回。让我们看看它的实际效果：

>>> multiply_by(3)
<function multiply_by.<locals>.multiply at ...>
>>> multiply(4)
Traceback (most recent call last):
File "<stdin>", line 1, in <module>
NameError: name 'multiply' is not defined

调用 multiply_by 会如预期那样返回一个函数。但是，调用 multiply 却会报错，尽管这正是我们给内部函数取的名字。这是因为名字 multiply 只存在于我们对 multiply_by 的函数体求值时的那个帧中。

那么我们究竟该如何使用这个内部函数呢？有两种方式：

>>> times_three = multiply_by(3) # Assign the result of the call expression to a name
>>> times_three(5) # Call the inner function with its new name
15
>>> multiply_by(3)(10) # Chain together two call expressions
30

关键在于，由于 multiply_by 返回的是一个函数，你可以像使用任何其他函数一样使用它的返回值。

Lambda 表达式

lambda 表达式是一种通过指定两样东西来求值为函数的表达式：参数和一个返回表达式。

lambda <parameters>: <return expression>

虽然 lambda 表达式和 def 语句都会创建函数对象，但它们之间有一些明显的区别。lambda 表达式的工作方式与其他表达式相同；正如数学表达式只是求值为一个数、并不会改变当前环境一样，lambda 表达式求值为一个函数时也不会改变当前环境。让我们仔细看看。

lambda def
类型 求值为一个值的表达式。 会改变环境的语句。
执行结果 创建一个匿名的 lambda 函数，没有内在名称。 创建一个带有内在名称的函数，并在当前环境中把它绑定到该名字。
对环境的影响 对 lambda 表达式求值不会创建或修改任何变量。 执行 def 语句既会创建一个新的函数对象，也会在当前环境中把它绑定到一个名字。
用法 凡是需要表达式的地方都可以使用 lambda 表达式，例如用在赋值语句中，或作为调用表达式的运算符或操作数。 执行 def 语句后，所创建的函数会绑定到一个名字。在凡是需要表达式的地方，你都应该用这个名字来引用该函数。
示例 
# A lambda expression by itself does not alter
# the environment
lambda x: x * x

# We can assign lambda functions to a name
# with an assignment statement
square = lambda x: x * x
square(3)

# Lambda expressions can be used as an operator
# or operand
negate = lambda f, x: -f(x)
negate(lambda x: x * x, 3)
 
def square(x):
    return x * x

# A function created by a def statement
# can be referred to by its intrinsic name
square(3)

Q4：复合恒等函数

编写一个函数，接收两个单参数函数 f 和 g，并返回另一个只有一个参数 x 的函数。如果 f(g(x)) 等于 g(f(x))，返回的函数应返回 True，否则返回 False。你可以假设 g(x) 的输出是 f 的有效输入，反之亦然。

def composite_identity(f, g):
    """
    Return a function with one parameter x that returns True if f(g(x)) is
    equal to g(f(x)). You can assume the result of g(x) is a valid input for f
    and vice versa.

    >>> add_one = lambda x: x + 1        # adds one to x
    >>> square = lambda x: x**2          # squares x [returns x^2]
    >>> b1 = composite_identity(square, add_one)
    >>> b1(0)                            # (0 + 1) ** 2 == 0 ** 2 + 1
    True
    >>> b1(4)                            # (4 + 1) ** 2 != 4 ** 2 + 1
    False
    """

    return lambda x: f(g(x)) == g(f(x))

    # Alternate solution:
    def h(x):
        return f(g(x)) == g(f(x))
    return h
我们必须用 lambda 或 def 创建一个接收 x 的函数，然后比较这两个量。

Q5：条件计数

考虑下面 count_fives 和 count_primes 的实现，它们用到了下面实现的 sum_digits 和 is_prime 函数：

def count_fives(n):
    """Return the number of values i from 1 to n (including n)
    where sum_digits(n * i) is 5.

    >>> count_fives(10)  # Among 10, 20, 30, ..., 100, only 50 (10 * 5) has digit sum 5
    1
    >>> count_fives(50)  # 50 (50 * 1), 500 (50 * 10), 1400 (50 * 28), 2300 (50 * 46)
    4
    """
    i = 1
    count = 0
    while i <= n:
        if sum_digits(n * i) == 5:
            count += 1
        i += 1
    return count

def count_primes(n):
    """Return the number of prime numbers up to and including n.

    >>> count_primes(6)   # 2, 3, 5
    3
    >>> count_primes(13)  # 2, 3, 5, 7, 11, 13
    6
    """
    i = 1
    count = 0
    while i <= n:
        if is_prime(i):
            count += 1
        i += 1
    return count

这些实现看起来非常相似！请编写函数 count_cond 来推广这一逻辑，它接收一个双参数的谓词函数 condition(n, i)。count_cond 返回一个单参数函数，该函数接收 n，并统计 1 到 n 中所有在被调用时满足 condition 的数。

注意： 当我们说 condition 是一个谓词函数时，意思是它会返回 True 或 False。

def sum_digits(y):
    """Return the sum of the digits of non-negative integer y."""
    total = 0
    while y > 0:
        total, y = total + y % 10, y // 10
    return total

def is_prime(n):
    """Return whether positive integer n is prime."""
    if n == 1:
        return False
    k = 2
    while k < n:
        if n % k == 0:
            return False
        k += 1
    return True

def count_cond(condition):
    """Returns a function with one parameter N that counts all the numbers from
    1 to n that satisfy the two-argument predicate function Condition, where
    the first argument for condition is n and the second argument is the
    number from 1 to n.

    >>> count_fives = count_cond(lambda n, i: sum_digits(n * i) == 5)
    >>> count_fives(10)   # 50 (10 * 5)
    1
    >>> count_fives(50)   # 50 (50 * 1), 500 (50 * 10), 1400 (50 * 28), 2300 (50 * 46)
    4

    >>> is_i_prime = lambda n, i: is_prime(i) # need to pass 2-argument function into count_cond
    >>> count_primes = count_cond(is_i_prime)
    >>> count_primes(2)    # 2
    1
    >>> count_primes(3)    # 2, 3
    2
    >>> count_primes(4)    # 2, 3
    2
    >>> count_primes(5)    # 2, 3, 5
    3
    >>> count_primes(20)   # 2, 3, 5, 7, 11, 13, 17, 19
    8
    """

    def counter(n):
        i = 1
        count = 0
        while i <= n:
            if condition(n, i):
                count += 1
            i += 1
        return count
    return counter

有一道题或许值得提出：count_fives 和 count_primes 的逻辑在哪些方面相似，又在哪些方面不同？

第一个问题的答案可以告诉我们想在 count_cond 函数中包含哪些逻辑，而第二个问题的答案可以告诉我们：在 count_cond 的哪个位置，我们希望能观察到 count_fives 与 count_primes 之间行为的差异。

还有一点也要牢记：我们希望 count_cond 返回一个函数，当向它传入参数 n 时，它的行为会与 count_fives 或 count_primes 类似。换句话说，count_cond 是一个返回函数的高阶函数，而返回的那个函数则包含 count_fives 和 count_primes 共有的逻辑。

Q6：字符串转换器

使用 lambda 表达式补全下面的函数。你的函数应该只包含一个 return 语句。

from operator import add, sub

def caesar_generator(num, op):
    """Returns a one-argument Caesar cipher function. The function should "rotate" a
    letter by an integer amount 'num' using an operation 'op' (either add or
    sub).

    You may use the provided `letter_to_num` and `num_to_letter` functions,
    which will map all lowercase letters a-z to 0-25 and all uppercase letters
    A-Z to 26-51.

    >>> letter_to_num('a')
    0
    >>> letter_to_num('c')
    2
    >>> num_to_letter(3)
    'd'

    >>> caesar2 = caesar_generator(2, add)
    >>> caesar2('a')
    'c'
    >>> brutus3 = caesar_generator(3, sub)
    >>> brutus3('d')
    'a'
    """

    return lambda char: num_to_letter(op(letter_to_num(char), num))

Q7：回文数

如果一个数正着读和倒着读都一样，它就被认为是回文数。请填写空白处 '_'，以帮助判断一个数是否为回文数。本着考试题的精神，除空白处外，请不要修改函数的任何其他部分。

def is_palindrome(n):
    """
    Fill in the blanks '_____' to check if a number
    is a palindrome.

    >>> is_palindrome(12321)
    True
    >>> is_palindrome(42)
    False
    >>> is_palindrome(2015)
    False
    >>> is_palindrome(55)
    True
    """
    x, y = n, 0

    f = lambda: y * 10 + x % 10
    while x > 0:

        x, y = x // 10, f()
    return y == n
