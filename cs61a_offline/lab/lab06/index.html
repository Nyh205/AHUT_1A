面向对象编程

这里是对面向对象编程的复习。你可以直接跳到题目部分，遇到困难时再回来查阅。

面向对象编程（OOP）使用对象和类来组织程序。下面是一个类的例子：

class Car:
    max_tires = 4

    def __init__(self, color):
        self.tires = Car.max_tires
        self.color = color

    def drive(self):
        if self.tires < Car.max_tires:
            return self.color + ' car cannot drive!'
        return self.color + ' car goes vroom!'

    def pop_tire(self):
        if self.tires > 0:
            self.tires -= 1

类（Class）：对象的类型。Car 类（如上所示）描述了所有 Car 对象的特征。

对象（Object）：类的一个实例。在 Python 中，通过调用类来创建新对象。

>>> ferrari = Car('red')

这里，ferrari 是一个绑定到 Car 对象的名字。

类属性：属于类的变量，通过点号访问。Car 类有一个 max_tires 属性。

>>> Car.max_tires
4

实例属性：属于某个具体对象的变量。每个 Car 对象都有一个 tires 属性和一个 color 属性。与类属性一样，实例属性也通过点号访问。

>>> ferrari.color
'red'
>>> ferrari.tires
4
>>> ferrari.color = 'green'
>>> ferrari.color
'green'

方法：属于对象的函数，通过点号调用。按照约定，方法的第一个参数是 self。

当调用对象的某个方法时，该对象会被隐式地作为 self 的参数传入。例如，ferrari 对象的 drive 方法是用空括号调用的，因为 self 被隐式地绑定到 ferrari 对象。

>>> ferrari = Car('red')
>>> ferrari.drive()
'red car goes vroom!'

我们也可以调用最初的 Car.drive 函数。这个原始函数不属于任何特定的 Car 对象，所以我们必须显式地为 self 传入参数。

>>> ferrari = Car('red')
>>> Car.drive(ferrari)
'red car goes vroom!'

__init__：一种特殊函数，在创建类的新实例时会自动调用。

注意 drive 方法接收 self 作为参数，但看起来我们并没有传入它！这是因为点号表示法隐式地帮我们把 ferrari 作为 self 传了进去。所以在这个例子里，self 绑定到全局帧中名为 ferrari 的那个对象。

求值表达式 Car('red') 时，Python 会创建一个新的 Car 对象。然后，Python 调用 Car 类的 __init__ 函数，把 self 绑定到新对象，把 color 绑定到 'red'。

继承

两个类可能具有相似的属性，但其中一个表示另一个的特殊情形。例如，Nickel 是 Coin 的一种特殊情形。我们说 Nickel 是 Coin 的子类，而 Coin 是 Nickel 的基类（或超类）。在 Python 中，class Nickel(Coin): 这一行就建立了这种关系。

class Coin:
    cents = None  # This will be provided by subclasses, but not by Coin itself

    def __init__(self, year):
        self.year = year

class Nickel(Coin):
    cents = 5

Coin 的方法（例如 __init__）也是 Nickel 的方法。因此，每个 Nickel 实例都有 year 属性。但定义在 Nickel 类中的类属性或方法会优先被找到。

>>> c = Nickel(1990)
>>> c.year
1990
>>> c.cents
5
